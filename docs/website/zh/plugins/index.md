# 插件与方案

**插件负责解决具体业务问题，PowerX 负责让这些能力在同一个底座上运行和协作。** 先选业务切入点，再决定是否需要流程与 AI。

## 核心付费插件

### CRM：让客户跟进有连续的上下文

当客户信息、销售进度和跟进记录分散在不同表格或个人手中，团队很难知道“谁在负责、进行到哪、下一步做什么”。CRM 围绕客户与销售协作组织业务，作为连接后续服务和营销工作的起点。

### MediaXStudio：让内容工作有统一入口

内容团队需要持续准备、管理和复用素材。MediaXStudio 面向内容与媒体工作，把分散的内容操作组织起来，为内容生产与业务协作提供插件入口。

两者属于核心付费插件。具体功能范围、交付方式与二次开发权限以相应版本和授权为准；平台底座的开源许可不代表商业插件免费或源码公开。

## 不止安装，还能按业务扩展

- **现有插件适合**：先验证一条真实业务操作，避免一开始铺开所有模块。
- **需要自己的字段、流程或界面**：在许可允许的范围内二次开发，或编写自定义插件。
- **已有外部系统**：通过接口、事件和能力契约接入，逐步复用身份、权限、通知、任务等底座能力。

插件可以向平台登记能力，再由流程或智能体按授权调用。共享的是可受控调用的业务能力，不是无边界开放插件数据。详见[开发与扩展](/zh/developers/)。

## 用一个场景验证价值

从“客户线索 → 内容准备 → 跟进任务”这样的最小流程开始：先记录业务，再连接步骤，最后考虑让 AI 辅助判断与执行。参见[点、线、面的示例](/zh/overview/#guiding-scenarios)。
