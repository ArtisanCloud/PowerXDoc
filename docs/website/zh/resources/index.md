# 资源中心

集中整理 PowerX 对外共享或内部协作所需的资源，便于产品、销售、实施与技术团队快速查找。

## 下载与工具 {#downloads}

- 发布包、示例插件、测试数据等资料建议统一放置于对象存储或公开仓库，并在此维护链接。
- 常用脚本：`scripts/publish/*.mjs`、`scripts/qa/workflow-metrics.mjs`、`scripts/localization/*.mjs`。
- 推荐引导用户先阅读使用说明，再下载对应工具。

## 版本与公告 {#release-notes}

- 记录平台版本、插件 SDK、PXIP 等迭代节奏。
- 建议对主要功能变更、破坏性修改与安全修复做简明摘要，并链接到详细变更日志。
- 可将发布公告同步到市场页面或社区渠道。

## 术语表 {#glossary}

- PowerX 核心术语（SCN、Seed、Capability、PXIP 等）的统一解释。
- 保持中英对照，便于国际化团队与外部客户沟通。
- 如术语定义更新，请同步到 `docs/meta` 中的标准文档。
