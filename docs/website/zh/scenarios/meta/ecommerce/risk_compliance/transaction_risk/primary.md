# 主用例说明：交易风控

## 背景概述
PowerX 电商平台需要为用户提供强大的交易风控能力，支撑异常识别、风险拦截、监控报警。随着交易风险增加，风控系统成为保障资金安全的关键。本主用例聚焦"交易风控"全流程，覆盖高额订单监控、黑名单拦截、异常支付阻断三大核心场景，确保交易安全、风险可控。

## 核心子场景

### 子场景 A：高额订单审核
- **主要流程**：检测到同 IP 多笔高额订单，自动触发人工审核，审核通过后正常发货。

### 子场景 B：黑名单用户拦截
- **主要流程**：黑名单用户下单自动拦截，记录拦截事件，防止欺诈交易。

### 子场景 C：异常支付阻断
- **主要流程**：检测到异常支付尝试，支付网关自动阻断并报警，保障资金安全。

## 验收要点
1. 高额订单识别及时，拦截准确率≥95%。
2. 黑名单拦截有效，拦截率 100%。
3. 异常支付阻断及时，误报率≤5%。
