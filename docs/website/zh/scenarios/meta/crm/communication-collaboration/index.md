# 沟通与协同 (Communication & Collaboration)

沟通与协同模块围绕企业微信等社交触点统一管理客户沟通、任务协作与渠道伙伴协同，确保信息透明、响应及时。

## 子场景

- **[全渠道沟通记录](./omnichannel-communication-logging/primary.md)** - 电话、邮件、会议纪要一体化留痕
- **[任务与节奏协同](./task-cadence-collaboration/primary.md)** - 线索任务分配、跨部门协作与提醒
- **[渠道与伙伴协作](./channel-partner-collaboration/primary.md)** - 伙伴进展同步、需求变更审批与业绩结算
