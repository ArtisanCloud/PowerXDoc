# 主用例说明：内容与渠道触达（Content & Channel Outreach）

## 背景概述

高效的营销自动化离不开多渠道内容协同。PowerX CRM 支持模板管理、内容复用与渠道排程，帮助运营团队在保持品牌一致性的同时实现多语言、多地区触达。本主用例聚焦“内容与渠道触达”，覆盖邮件、社媒、短信等渠道运营。

## 目标与价值
- **模板复用**：统一内容资产，降低制作成本。
- **多语言管理**：支持翻译、校对与多地区上架。
- **渠道排程**：按渠道规则自动排期发布。
- **合规留痕**：审批、发布、回溯全程留痕。
- **数据闭环**：收集各渠道互动数据，为优化提供依据。

## 参与角色
- **内容团队**：撰写模板、管理素材。
- **市场运营**：排期、发布、监控效果。
- **合规团队**：审核内容符合品牌与法规要求。
- **系统 Agent**：调度渠道、收集数据、推送提醒。

## 主场景 User Story
> **作为** 市场内容运营，**我希望** 在 CRM 中统一管理多渠道内容发布，**从而** 保持品牌一致并提升触达效率。

## 子场景详解

### 子场景 A：模板管理与多语言版本
- **角色与触发**：市场人员创建邮件模板并复用动态内容块，系统自动进行多语言版本管理。
- **主要流程**：
  1. 在内容库中创建主模板，插入可配置变量与动态区块。
  2. 系统自动生成多语言副本，支持翻译流程与审核。
  3. 模板通过合规审批后，发布到营销活动中。
  4. 更新模板会提醒关联活动同步更新。
- **成功标准**：模板管理集中；多语言版本同步；审批及时。
- **异常与风控**：未审批模板禁止发布；版本冲突提示；敏感词检测。
- **指标建议**：模板复用率、翻译周期、审批通过率。

### 子场景 B：社交媒体排程与数据采集
- **角色与触发**：社交媒体计划排程后，系统按平台规范自动发布并收集互动数据。
- **主要流程**：
  1. 选择目标平台（LinkedIn、微博等），设置发布时间与内容。
  2. 系统检查字数、配图、话题等符合各平台规则。
  3. 到时间自动发布，并记录曝光、互动、点击数据。
  4. 数据回写至活动仪表盘，供分析与优化。
- **成功标准**：排程准确；发布成功；数据完整。
- **异常与风控**：平台接口异常自动重试；敏感话题预警；权限控制。
- **指标建议**：发布成功率、互动率、排程冲突率。

### 子场景 C：统一短信/推送触达
- **角色与触发**：SMS/推送等渠道由自动化引擎统一调用，确保节奏与内容一致。
- **主要流程**：
  1. 在旅程中配置短信/推送节点，指定模板与变量。
  2. 系统调用短信网关或推送服务发送消息。
  3. 记录送达、点击、退订状态，与用户档案关联。
  4. 控制频次，避免同一用户短时间收到多条消息。
- **成功标准**：发送成功率高；频次受控；退订合规。
- **异常与风控**：网关失败自动切换备用通道；退订名单实时同步；消息内容审核。
- **指标建议**：送达率、点击率、退订率、频次违规数。

### 子场景 D：内容审批与发布追踪
- **角色与触发**：内容素材审批通过后，系统更新品牌资产库并留存审计轨迹。
- **主要流程**：
  1. 内容提交审批，合规团队在线批注。
  2. 审批通过后自动更新资产库状态，并记录审批链条。
  3. 发布后生成审计日志，包含发布人、时间、渠道。
  4. 违反规范的内容可一键下架，并通知相关负责人。
- **成功标准**：审批流程顺畅；审计记录完整；下架机制有效。
- **异常与风控**：审批超时升级；重复审批合并；资产库版本控制。
- **指标建议**：审批时长、驳回率、下架响应时间。

## 场景级测试用例示例

> 测试准备：启用内容模板库、多语言管理、社媒排程、短信网关、审批流程与审计日志。准备中文/英文模板各 1 份、社媒账号 2 个、短信供应商主备各 1 套。

### 用例 A-1：模板多语言同步（正向）
- **前置条件**：主模板含动态变量 {{industry}}；翻译流程已配置。
- **操作步骤**：
  1. 创建中文模板并提交翻译任务。
  2. 审核后发布。
- **预期结果**：
  - 英文、日文副本自动生成并进入翻译任务列表。
  - 审核通过后副本状态为“可用”，版本号与主模板保持一致。
  - 模板更新后提示同步修改副本。

### 用例 B-1：社交媒体排程执行（正向）
- **前置条件**：计划在 LinkedIn 与微博发布内容；规则检查启用。
- **操作步骤**：
  1. 设置定时发布时间。
  2. 等待执行并查看日志。
- **预期结果**：
  - 系统检查字符数、话题格式均符合要求。
  - 到点自动发布，并记录曝光、互动数据回写 CRM。
  - 若某平台失败，触发重试并告警。

### 用例 C-1：短信频次控制（正向）
- **前置条件**：同一用户短信频次限制为 3 条/24 小时。
- **操作步骤**：
  1. 向同一用户发送 3 条活动短信。
  2. 尝试发送第 4 条。
- **预期结果**：
  - 前 3 条发送成功并记录送达、点击状态。
  - 第 4 条被拦截，提示“超过频次限制”。
  - 系统建议改用其他渠道。

### 用例 D-1：内容审批与追踪（正向）
- **前置条件**：内容需合规团队审批；审计开启。
- **操作步骤**：
  1. 提交内容审批。
  2. 合规人员批注并通过。
- **预期结果**：
  - 审批流显示批注意见，审批通过后内容状态变为“可发布”。
  - 发布后生成审计日志，记录发布人/时间/渠道。
  - 可按内容 ID 查询完整历史。

### 用例 D-2：违规内容下架（逆向）
- **前置条件**：发布后发现内容含违禁词。
- **操作步骤**：
  1. 合规人员点击“一键下架”。
- **预期结果**：
  - 内容立即从所有渠道撤回，并通知运营负责人。
  - 生成整改任务及复盘报告模板。
