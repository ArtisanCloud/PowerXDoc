# 数据洞察与营收预测 (Analytics & Revenue Intelligence)

数据洞察与营收预测模块整合商机、订单、服务与满意度数据，支持目标拆解、预测预警与价值分析，驱动数据化增长。

## 子场景

- **[销售预测与目标管理](./sales-forecasting-target-management/primary.md)** - 目标拆解、预测曲线与偏差预警
- **[客户价值与流失分析](./customer-value-churn-analysis/primary.md)** - 价值分层、流失预警与原因分析
- **[绩效与激励结算](./performance-incentive-settlement/primary.md)** - 业绩统计、佣金审批与发放风险控制
