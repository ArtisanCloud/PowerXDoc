# 业务场景文档

本文档集合展示了 PowerX 平台在各个业务领域的场景化用例设计，涵盖从用户需求到系统实现的完整业务蓝图。

## 业务领域

### 🧩 PowerX 平台 (PowerX)
- **路径**：[PowerX 场景文档](./powerx/)
- **涵盖**：智能体编排、插件生态、核心平台、市场运营等

### 🛒 电商业务 (Ecommerce)
- **路径**：[电商场景文档](./ecommerce/)
- **涵盖**：订单履约、支付结算、库存管理、会员营销、风险合规等

### 👥 客户关系管理 (CRM)
- **路径**：[CRM 场景文档](./crm/)
- **涵盖**：客户管理、销售流程等

### 🔄 社会化客户关系管理 (SCRM)
- **路径**：[SCRM 场景文档](./scrm/)
- **涵盖**：社交化营销、客户互动等

## 文档结构说明

每个业务领域采用三层结构：
> **类别（Category）→ 主用例（Primary Use Case）→ 子用例（Scenario Use Case）**

每个子用例遵循「角色 + 触发 + 行为 + 目标」的叙事风格，确保具备真实业务场景感。
