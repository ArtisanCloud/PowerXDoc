# 主用例说明：多渠道统一接入（Unified Social Channel Access）

## 背景概述

企业越来越依赖企业微信、视频号、公众号、抖音、小红书等多种社交触点与客户互动。若各渠道独立运维，不仅增加运营成本，也难以统一追踪触达效果。本主用例聚焦渠道接入、健康检测、归因与测试账号管理，帮助企业将所有社交触点纳入 SCRM 中心，实现“入口统一、数据统一、监控统一”。

## 目标与价值
- **快速接入**：标准化流程“一键接入”新渠道，降低技术门槛。
- **统一监控**：持续监测渠道状态，出现异常时及时告警。
- **数据归因**：确保线索、互动数据带有渠道标识，支持 ROI 分析。
- **测试隔离**：提供联调环境与测试账号，保障生产环境稳定。

## 参与角色
- **市场运营**：发起渠道接入、配置活码与归因参数。
- **渠道/伙伴运营**：负责外部平台授权、账号维护。
- **数据分析团队**：建设渠道归因模型与报表。
- **IT/平台团队**：维护接入网关、监控与日志。
- **安全合规团队**：审核授权范围与平台协议。

## 主场景 User Story
> **作为** 市场运营负责人，**我希望** 在一个平台统一管理所有社交触点并掌握状态和数据归因，**从而** 快速落地营销活动并评估投入产出。

## 子场景详解

### 子场景 A：新渠道标准化接入
- **角色与触发**：运营需要接入新的公众号或短视频账号。
- **主要流程**：
  1. 在线选择渠道类型与业务场景，系统展示所需信息与授权步骤。
  2. 提交渠道凭证或扫描授权二维码，完成 API 授权。
  3. 配置渠道标签、默认归因参数、测试活码。
  4. 提交审批后自动生成接入报告与联调清单。
- **成功标准**：授权成功且渠道状态为“健康”；数据可在 5 分钟内同步到 SCRM；审批与操作留痕完整。
- **异常与风控**：授权失败提示错误原因并可重试；凭证过期自动告警；多次失败时通知平台团队介入。
- **指标建议**：接入平均时长、一次成功率、渠道上线周期。

### 子场景 B：渠道健康与数据监控
- **角色与触发**：平台自动定时巡检或运营关注异常数据。
- **主要流程**：
  1. 系统每小时检测渠道接口响应状态、延迟与错误率。
  2. 指标超阈值触发告警（如粉丝数据停更、接口 5xx）。
  3. 平台提供快速自检工具（凭证刷新、日志查询）。
  4. 异常处理完成后更新状态并生成复盘报告。
- **成功标准**：监控覆盖接入渠道；异常响应及时；运营可自助排查。
- **异常与风控**：无法恢复时自动暂停数据同步；向业务发送风险提示；提供冗余方案（备用号或缓存）。
- **指标建议**：健康巡检覆盖率、告警响应时间、故障恢复时长。

### 子场景 C：渠道归因与活码管理
- **角色与触发**：运营为活动创建活码并希望记录渠道来源。
- **主要流程**：
  1. 在 SCRM 创建活码，选择渠道、活动、责任人。
  2. 系统自动生成参数链接（UTM、渠道 ID），并与线索模型关联。
  3. 活码使用情况实时统计，支持按渠道、活动筛选。
  4. 活动结束后可导出归因报告，为投放决策提供依据。
- **成功标准**：线索入库带有渠道标签；归因报表准确；活码生命周期可控。
- **异常与风控**：活码私自外传触发告警；过期活码自动失效；支持批量更新或停用。
- **指标建议**：活码转化率、归因准确率、渠道 ROI。

### 子场景 D：测试环境与隔离机制
- **角色与触发**：新功能上线或渠道参数变更需要测试。
- **主要流程**：
  1. 申请测试渠道或测试账号，系统分配沙箱环境。
  2. 模拟不同事件（关注、扫码、下单）验证数据链路。
  3. 测试通过后自动生成上线 checklist。
  4. 上线后继续观察指标，如异常可一键回滚配置。
- **成功标准**：测试环境与生产隔离；测试用例完整；上线风险可控。
- **异常与风控**：测试调用过多触发限流时提示调整；测试忘记关闭提醒；系统记录变更版本便于回滚。
- **指标建议**：测试缺陷率、上线后故障率、回滚次数。

## 场景级测试用例示例

> 测试准备：配置新渠道授权凭证、模拟 API、健康监控阈值、活码模板与测试账号。

### 用例 A-1：公众号接入与数据同步（正向）
- **前置条件**：公众号授权凭证有效；审批人在线。
- **操作步骤**：
  1. 在渠道接入向导中选择“公众号”，填写必要信息。
  2. 扫描授权二维码并提交审批。
  3. 发送一次测试消息，检查 SCRM 中的数据呈现。
- **预期结果**：
  - 授权成功后渠道状态为“健康”，5 分钟内收到测试消息数据。
  - 审批、授权日志完整可查。
  - 活码列表自动生成默认测试活码。

### 用例 B-1：渠道凭证过期告警（逆向）
- **前置条件**：手动禁用接口凭证，模拟过期。
- **操作步骤**：
  1. 等待监控任务巡检。
  2. 查看告警通知与自检面板。
- **预期结果**：
  - 在巡检周期内触发红色告警，通知运营和平台团队。
  - 自检面板显示“凭证失效”并提供刷新入口。
  - 恢复凭证后状态变为“正常”，故障评估报告生成。
