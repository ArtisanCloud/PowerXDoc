# 主用例说明：社交触点数据看板（Social Touchpoint Dashboard）

## 背景概述

企业微信触点覆盖客户添加、群互动、内容触达、交易转化。缺乏统一数据看板，会导致运营盲飞、决策滞后。本主用例提供跨触点数据看板设计：实时指标、漏斗、对比分析、预警，为管理层与运营提供可视化洞察。

## 目标与价值
- **全局视角**：统一展示好友增长、群活跃、内容点击、订单转化。
- **实时预警**：指标异常自动告警，快速响应。
- **多维分析**：按渠道、部门、员工、活动对比。
- **行动指引**：支持钻取至客户、线索、活动信息，形成行动。

## 参与角色
- **管理层/运营总监**：关注整体指标与策略。
- **社群运营/营销**：查看活动效果。
- **销售主管**：分析触达与转化表现。
- **数据分析**：维护模型、指标与数据质量。
- **IT 中台**：保障数据管道、权限、安全。

## 主场景 User Story
> **作为** 运营总监，**我希望** 在一个看板中查看私域核心指标并获得预警，**从而** 快速做出决策。

## 子场景详解

### 子场景 A：指标体系与看板设计
- **角色与触发**：需要搭建全局看板。
- **主要流程**：
  1. 定义指标（新增好友、活跃度、留存、GMV 等）及口径。
  2. 设计看板布局：漏斗、趋势、排行榜。
  3. 接入数据源（企业微信、CRM、订单、活动平台）。
  4. 设置刷新频率与权限。
- **成功标准**：指标统一、可解释；看板易用；权限安全。
- **异常与风控**：数据断链告警；指标冲突需审批；敏感数据脱敏。
- **指标建议**：指标覆盖率、刷新时效、用户访问量。

### 子场景 B：多维钻取与联动分析
- **角色与触发**：管理层希望查看某渠道表现。
- **主要流程**：
  1. 在看板上选择渠道、部门、员工等维度。
  2. 钻取到具体活动、客户或群。
  3. 结合历史数据对比，分析异常原因。
  4. 一键生成任务或通知相关负责人。
- **成功标准**：钻取流畅；分析可执行；行动闭环。
- **异常与风控**：访问无权限数据时提示；数据量过大需分页；记录钻取日志。
- **指标建议**：钻取使用率、问题解决率、行动转化率。

### 子场景 C：预警与自动化建议
- **角色与触发**：指标超出阈值或趋势异常。
- **主要流程**：
  1. 设置预警规则（如新增好友下滑、活跃度降低）。
  2. 指标异常时自动推送预警至企业微信。
  3. 附带建议（如发布内容、开展活动、调整策略）。
  4. 跟踪预警处理结果。
- **成功标准**：预警及时；建议有用；处理闭环。
- **异常与风控**：频繁误报需调整阈值；未处理升级提醒；保留日志。
- **指标建议**：预警命中率、处理时长、改善幅度。

### 子场景 D：报告生成与共享
- **角色与触发**：需要周期性汇报。
- **主要流程**：
  1. 一键生成日报、周报、月报，支持自定义模板。
  2. 报告可导出 PDF/Excel，或推送至企业微信群。
  3. 设置收件人、查看权限与截止时间。
  4. 收集反馈，优化报告内容。
- **成功标准**：报告准确、及时；阅读率高；反馈快速。
- **异常与风控**：导出失败自动重试；敏感版报告需审批；记录阅读日志。
- **指标建议**：报告准时率、阅读率、反馈采纳率。

## 场景级测试用例示例

> 测试准备：搭建数据仓库、BI 看板、预警规则、报告模板及权限配置。

### 用例 A-1：多维钻取分析（正向）
- **前置条件**：看板已配置渠道、部门、员工维度。
- **操作步骤**：
  1. 选择“直播活动渠道”，钻取至具体活动。
  2. 查看转化指标与参与用户列表。
- **预期结果**：
  - 看板实时展示该活动的触达、报名、成交数据。
  - 可一键导出客户列表，生成跟进任务。
  - 日志记录操作轨迹。

### 用例 B-1：指标异常预警（逆向）
- **前置条件**：设置“新增好友较上周下降 30%”预警。
- **操作步骤**：
  1. 模拟下降趋势。
  2. 查看预警通知与处理流程。
- **预期结果**：
  - 系统推送预警到运营群，并附处理建议。
  - 运营填写处理结果，预警状态更新。
  - 若未处理，24 小时后升级至主管。
