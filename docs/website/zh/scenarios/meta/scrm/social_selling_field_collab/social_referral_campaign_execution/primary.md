# 主用例说明：客群裂变与活动执行（Social Referral & Campaign Execution）

## 背景概述

私域增长依赖裂变活动：老客带新、组队拼团、转介绍奖励。没有系统支撑，很难追踪链路、控制风险。本主用例描述如何在企业微信中执行裂变活动，包括策略设计、素材分发、链路追踪、激励发放与风控监测。

## 目标与价值
- **高效策划**：模板化设计裂变活动，快速上线。
- **精准追踪**：识别每个邀请者、被邀请者及转化结果。
- **激励闭环**：奖励自动计算、发放、复核。
- **风险控制**：防止刷量、虚假邀请、违规传播。

## 参与角色
- **市场/运营团队**：设计活动、配置奖励、分析效果。
- **销售/社群运营**：执行活动、推动裂变、服务客户。
- **客户**：成为邀请者或被邀请者。
- **财务/风控**：审核激励、监控风险。
- **数据团队**：分析活动数据、提供优化建议。

## 主场景 User Story
> **作为** 市场运营，我希望快速搭建裂变活动并实时掌握效果，**从而** 拓展客户群并保证激励准确。

## 子场景详解

### 子场景 A：裂变活动配置与上线
- **角色与触发**：计划上线“老带新”活动。
- **主要流程**：
  1. 选择活动模板，配置活动时间、目标、奖励。
  2. 系统生成专属分享链接、海报、话术。
  3. 设置规则（成功定义、限制条件、风控预警）。
  4. 一键发布至社群、私聊、朋友圈。
- **成功标准**：配置简洁；素材完整；上线无误。
- **异常与风控**：参数冲突提示；敏感内容需审批；活动暂停与恢复可控。
- **指标建议**：活动上线时长、素材复用率、参与人数。

### 子场景 B：邀请链路追踪与看板
- **角色与触发**：活动执行时需要实时监控。
- **主要流程**：
  1. 系统记录邀请人、被邀请人、渠道、时间。
  2. 可视化展示裂变树和转化漏斗。
  3. 提供排行榜、TOP 合伙人列表。
  4. 异常行为（同设备、多账号）自动标记。
- **成功标准**：数据准确；监控实时；可快速定位问题。
- **异常与风控**：网络延迟导致数据缺失时补偿；支持导出报表；敏感数据脱敏。
- **指标建议**：有效邀请数、转化率、活跃度。

### 子场景 C：激励发放与复核
- **角色与触发**：活动结束或达到奖励条件。
- **主要流程**：
  1. 系统根据规则计算奖励（优惠券、积分、现金）。
  2. 自动发放至客户账户，并通知获奖者。
  3. 财务可复核高额奖励，确认后发放。
  4. 生成激励报告与税务数据。
- **成功标准**：奖励准确及时；客户体验好；账务清晰。
- **异常与风控**：奖励争议可申诉；风控标记订单先冻结；记录全部操作。
- **指标建议**：奖励发放及时率、争议率、复核通过率。

### 子场景 D：活动效果评估与复用
- **角色与触发**：活动结束后复盘。
- **主要流程**：
  1. 统计新增客户、成交额、老客活跃度。
  2. 分析不同渠道、话术、素材表现。
  3. 根据结果调整激励强度、策略、目标人群。
  4. 将优秀案例沉淀为模板。
- **成功标准**：复盘全面；策略迭代快速；经验可复用。
- **异常与风控**：数据缺失时补录；复盘报告权限控制；保留历史版本。
- **指标建议**：活动 ROI、老客活跃度提升、模板复用率。

## 场景级测试用例示例

> 测试准备：创建裂变活动模板、配置奖励规则、风控策略、看板和排行榜。

### 用例 A-1：邀请链路追踪（正向）
- **前置条件**：设置活动奖励“邀请 3 人注册送礼包”。
- **操作步骤**：
  1. 邀请者分享链接给 3 位好友。
  2. 好友完成注册。
- **预期结果**：
  - 看板显示邀请链路，每位好友状态清晰。
  - 达成条件后系统自动发放奖励给邀请者。
  - 日志记录分享渠道与时间。

### 用例 B-1：刷量风控拦截（逆向）
- **前置条件**：同设备、同 IP 快速注册多个账号。
- **操作步骤**：
  1. 模拟刷量行为。
  2. 查看风控处理。
- **预期结果**：
  - 系统识别异常并标记“疑似刷量”，冻结激励。
  - 风控团队收到审核任务，必要时封禁账户。
  - 活动报表自动扣除异常数据。
