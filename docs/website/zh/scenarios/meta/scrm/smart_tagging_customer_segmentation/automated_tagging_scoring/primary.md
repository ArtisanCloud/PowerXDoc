# 主用例说明：标签自动化运营（Automated Tagging & Scoring）

## 背景概述

社交渠道产生大量行为数据，如群发言、点击、购买、反馈等。手工打标签效率低，且难以实时应用。本主用例聚焦自动化标签体系：从数据采集、规则引擎、评分模型到应用场景，帮助企业构建标准化标签管理能力，为营销、销售、客服提供依据。

## 目标与价值
- **自动打标**：基于行为、属性、模型规则实时生成标签。
- **标签治理**：统一命名、层级、版本，避免重复与冲突。
- **评分体系**：将标签转化为客观分值，指导优先级。
- **多场景应用**：标签直接驱动旅程、推荐、话术等。

## 参与角色
- **数据分析/标签运营**：维护标签标准、规则与模型。
- **市场与社群运营**：消费标签用于分群、活动。
- **销售与客服**：在一线使用标签洞察。
- **IT 中台**：搭建标签引擎与治理平台。
- **合规团队**：审查敏感标签与隐私数据。

## 主场景 User Story
> **作为** 标签运营经理，**我希望** 自动生成高质量标签并治理生命周期，**从而** 支撑精准营销与精细化运营。

## 子场景详解

### 子场景 A：标签模板与规则配置
- **角色与触发**：标签运营需要上线新标签。
- **主要流程**：
  1. 在标签目录中定义标签名称、分类、取值类型、更新周期。
  2. 配置规则（行为触发、字段映射、模型输出）。
  3. 审批通过后发布到标签引擎，并生成测试用例。
  4. 通过沙箱校验数据准确性。
- **成功标准**：标签定义完整；规则可执行；审批留痕。
- **异常与风控**：规则冲突提示；上线失败回滚；敏感标签需额外审批。
- **指标建议**：标签上线周期、审批通过率、规则错误率。

### 子场景 B：实时标签计算与写回
- **角色与触发**：客户行为发生时触发标签计算。
- **主要流程**：
  1. SCRM 接收行为事件（发言、点击、下单）。
  2. 标签引擎实时计算标签取值，更新客户画像。
  3. 标签结果写回 CRM/SCRM，触发相关旅程或推荐。
  4. 记录执行日志，支持追溯。
- **成功标准**：标签延迟低于 SLA；写回成功率高；旅程即时生效。
- **异常与风控**：事件缺失时使用默认值；连续失败告警；提供补算机制。
- **指标建议**：实时计算成功率、延迟、触发生效率。

### 子场景 C：标签评分与优先级
- **角色与触发**：将多个标签组合成评分体系。
- **主要流程**：
  1. 定义评分模型（如活跃度=行为权重+互动次数）。
  2. 定期计算并输出评分层级（A/B/C/D）。
  3. 在销售、客服界面展示评分，指导跟进优先级。
  4. 监控评分与实际转化的相关性，迭代权重。
- **成功标准**：评分易理解、可解释；与业务指标相关性强。
- **异常与风控**：评分偏差大时告警；支持人工调整；记录版本历史。
- **指标建议**：评分命中率、转化提升、模型迭代周期。

### 子场景 D：标签治理与归档
- **角色与触发**：标签数量增加，需要治理。
- **主要流程**：
  1. 定期扫描标签使用情况，识别冗余与冲突。
  2. 对低使用率或过期标签执行归档或合并。
  3. 关键标签进行稳定性监测与数据校验。
  4. 发布标签白皮书，指导业务使用。
- **成功标准**：标签库干净；命名规范；业务理解一致。
- **异常与风控**：归档前确认无依赖；冲突处理需审批；提供标签字典。
- **指标建议**：标签重复率、归档率、业务满意度。

## 场景级测试用例示例

> 测试准备：配置标签模板、事件模拟器、评分模型、治理规则与审计日志。

### 用例 A-1：实时打标签（正向）
- **前置条件**：标签“高互动用户”规则：7 天内互动 ≥ 5 次。
- **操作步骤**：
  1. 模拟客户在一周内发起 5 次互动。
  2. 查看标签执行结果。
- **预期结果**：
  - 行为发生后 1 分钟内标签取值变为“是”。
  - 旅程触发个性化消息；CRM 同步标签。
  - 日志记录规则命中与执行时间。

### 用例 B-1：标签冲突治理（逆向）
- **前置条件**：同客户被标记为“高价值”和“黑名单”。
- **操作步骤**：
  1. 运行冲突检测任务。
  2. 查看处理结果。
- **预期结果**：
  - 系统识别冲突，按照权重保留“黑名单”并记录原因。
  - 触发人工审核任务；冲突报告更新。
  - 相关旅程暂停执行，避免误触达。
