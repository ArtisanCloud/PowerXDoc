# 插件生态场景文档

本文档展示了 PowerX Plugin 插件开发与分发体系的核心场景。

## 发布模式

### 1️⃣ 本地调试模式
**目的**：便于开发者在本地环境快速验证插件功能与接口。

**流程**：
1. 在 PowerXPlugin 仓内使用 `px-plugin` 构建插件，生成编译输出目录（如 `dist/`）
2. 打开 **PowerX Web Admin** 后台页面（PowerX Core 仓库内模块）
3. 在插件管理区选择"从本地目录安装"
4. 系统调用 **PowerX Backend（px）** 完成插件安装与激活
5. 插件在本地生效，可直接调试和修改

**特征**：
- 不依赖 Marketplace
- 适合开发阶段
- 调试高效、反馈即时

### 2️⃣ 离线打包上传模式
**目的**：用于企业内网或无公网访问场景下的插件分发。

**流程**：
1. 开发者使用 `px-plugin` 打包插件，生成压缩包（如 `PowerXPluginNote-v1.0.0.zip`）
2. 登录 **PowerX Marketplace** 管理页面
3. 选择"离线安装包上传"功能
4. 上传插件压缩包并填写版本信息
5. 系统自动解压、验证并完成安装

**特征**：
- 适用于内网环境
- 支持批量分发
- 适合企业定制场景

### 3️⃣ 在线发布模式
**目的**：面向公共生态的插件发布与分发。

**流程**：
1. 开发者完成插件开发与测试
2. 使用 `px-plugin publish` 命令发布到 Marketplace
3. 填写插件信息：名称、描述、版本、图标等
4. 提交审核（自动化安全检查 + 人工审核）
5. 审核通过后在 Marketplace 上架
6. 用户可直接搜索、安装使用

**特征**：
- 公共生态分发
- 标准化发布流程
- 支持版本更新与回滚

## 开发工具

### CLI 工具
- **`px-plugin`** - 插件开发 CLI
  - 插件创建、构建、调试
  - 本地测试、模拟运行
  - 打包、签名、发布

- **`px-admin`** - 管理后台 CLI
  - 插件管理、启停控制
  - 权限配置、日志查看
  - 性能监控、诊断工具

- **`px-market`** - 市场管理 CLI
  - 插件上架、版本管理
  - 销售数据、收益统计
  - 审核流程、质量监控

## 技术架构

### 插件开发栈
- **语言**：基于 PowerXPlugin SDK
- **框架**：支持多种前端/后端技术栈
- **接口**：标准化插件接口协议
- **安全**：插件签名、沙箱隔离

### 分发机制
- **本地模式**：文件系统直接加载
- **离线模式**：压缩包上传与安装
- **在线模式**：Marketplace 生态分发
