# 主用例说明：PowerX Web / MiniApp 智能体交互界面

## 背景概述
PowerX 智能体交互界面承载终端用户与多智能体协作的入口，融合自然语言、结构化输入与知识引用，帮助用户在 Web 与 MiniApp 端快速发起复杂任务
并跟踪执行结果。随着插件能力与知识空间不断扩张，仅依靠单一聊天框难以满足业务流程化、可审计、可复用的需求。本主用例聚焦前端交互层如
何实现“意图识别 → Agent 调度 → 工具执行 → 结果回传”的可视化闭环，确保智能体在企业环境中的高效、可靠与可控运行。

## 目标与价值
- **多模输入统一入口**：支持文本、语音、图片、文档、表单等多模输入，一站式触发智能体任务。
- **实时透明协作**：以时间线或流程视图呈现智能体与插件的调用链路，提升可解释性与信任度。
- **知识驱动增强**：无缝连接知识空间、提示模板与 ReAct 策略，让用户组合多源上下文快速达成目标。
- **人机协同闭环**：当自动化受阻时支持人工接管、任务分派或补充说明，保障业务连续性。
- **安全与合规可追溯**：对话记录、上下文注入、指令历史与审计日志统一管理，便于合规检查与经验复用。

## 参与角色
- **终端用户/业务人员**：发起指令、查看执行进度、协同补充信息或接管任务。
- **智能体编排管理员**：配置推荐智能体、提示模板、上下文策略与回退流程。
- **知识空间管理员**：维护知识源、切分策略与引用权限，确保交互界面正确调用知识。
- **插件 Owner / Agent 提供方**：提供可调用的工具与任务节点，并输出可视化结果摘要。
- **安全与合规人员**：审计对话、审批敏感操作、定义日志留存与数据脱敏策略。
- **客服/支持团队**：处理用户反馈、接手失败任务或触发工单流程。

## 主场景 User Story
> **作为** 企业终端用户，**我希望** 在 PowerX Web / MiniApp 的智能体交互界面中通过自然语言或知识引用快速指挥智能体完成任务，并随时了解
> 执行状态与手动接管选项，**从而** 在确保安全合规的前提下高效完成业务流程并沉淀可复用的工作剧本。

## 子场景详解

### 子场景 A：多模输入与意图识别
- **角色与触发**：用户需要在对话框中描述复杂任务或上传资料，由系统自动解析意图。
- **主要流程**：
  1. 对话框支持文本、语音转写、截图、Excel/CSV、PDF 等文件上传，并自动提取关键字段。
  2. 系统结合意图识别、关键词、行业模板对指令进行分类，并匹配推荐的智能体或工作流。
  3. 界面展示推荐意图卡片（如“生成报表”“对合同做摘要”“发起审批流程”），用户可一键确认或编辑。
  4. 支持插入提示模板、常用指令片段或组织内最佳实践，提升输入效率。
- **成功标准**：意图匹配准确率达标；支持 2 秒内给出推荐；多模文件解析成功并给出可视化摘要。
- **异常与风控**：解析失败时提供手动选择 Agent；敏感文件需触发脱敏或审批；超大文件支持异步处理并提示进度。
- **指标建议**：意图命中率、模板复用率、文件解析成功率。

### 子场景 B：上下文与知识引用管理
- **角色与触发**：用户需要引用知识空间内容或历史对话以增强回答准确度。
- **主要流程**：
  1. 对话侧边栏展示可选的知识空间、标签与最近引用记录，支持搜索与拖拽插入。
  2. 用户可将知识片段、RAG 检索结果、表格列或知识图谱节点加入当前会话上下文。
  3. 系统在 ReAct 流程中自动记录“思考—行动—观察”步骤，并高亮引用的知识来源。
  4. 对话框支持上下文裁剪与隐私字段屏蔽，避免过多信息影响推理或泄露敏感数据。
- **成功标准**：知识引用可追溯；上下文注入不超限；多轮对话保持关联。
- **异常与风控**：引用权限不足时提示申请；知识片段过期或被删除需给出替代方案；上下文过长时自动摘要。
- **指标建议**：知识引用点击率、上下文裁剪成功率、ReAct 步骤可视化完整率。

### 子场景 C：多智能体协作与执行时间线
- **角色与触发**：任务需多个 Agent 或插件协作完成，用户希望实时掌握进度。
- **主要流程**：
  1. 执行视图以时间线/流程图展示各 Agent 的步骤、调用的插件、输入输出摘要与耗时。
  2. 系统支持展开每一步的日志、提示词与调用参数，必要时允许用户编辑并重放某一步。
  3. 对长时任务提供进度条、阶段性总结、预计完成时间，并允许用户追加补充信息。
  4. 当某 Agent 失败时自动触发预设回退或重试策略，并在界面中突出提示。
- **成功标准**：时间线展示实时更新；可展开查看详单；失败步骤可重试或回滚。
- **异常与风控**：循环调用需防止风暴；长时间无响应需告警并允许取消；敏感日志需做脱敏处理。
- **指标建议**：执行可视化加载耗时、失败步骤可恢复率、用户追加指令响应时间。

### 子场景 D：人工接管与协同处理
- **角色与触发**：智能体执行失败、等待人工决策或需要跨团队协同。
- **主要流程**：
  1. 当任务触发风险阈值（如高权限操作、异常响应）时，界面提示“请求人工协助”，并可指派到客服、专家或审批人。
  2. 人工接管时可在对话内补充说明、上传附件、修改执行参数，并将状态同步给原发起人。
  3. 支持将对话转化为工单、任务或知识库条目，自动关联上下文和执行记录。
  4. 完成后可将人工解决方案沉淀为新的提示模板或工作流节点，供后续复用。
- **成功标准**：接管通知可靠送达；人工操作结果写回执行历史；沉淀内容可复用并具备审计。
- **异常与风控**：接管超时需自动升级；人工操作需最小权限校验；敏感内容需遮蔽处理。
- **指标建议**：人工接管率、接管完成时长、沉淀模板复用率。

### 子场景 E：历史对话管理与可复用资产
- **角色与触发**：用户希望复用高质量对话、分享给团队或生成报告。
- **主要流程**：
  1. 对话列表支持按项目、标签、时间、参与 Agent 等维度检索与筛选。
  2. 用户可收藏、复制、导出对话，并生成结构化报告或工作流模板。
  3. 系统支持设置分享权限（仅自己/团队/租户），并追踪使用情况与评分反馈。
  4. 合规人员可在审计模式下查看完整日志、知识引用、人工干预记录，并导出留存。
- **成功标准**：对话检索准确；导出格式多样（PDF、Markdown、JSON）；分享权限与租户隔离严格。
- **异常与风控**：过期或撤回的对话需标记不可再用；导出失败需重试与告警；审计模式需遮蔽敏感字段。
- **指标建议**：对话复用率、报告生成成功率、审计检索耗时。

## 功能边界 & 非目标场景
- 不直接实现插件内部 UI 或业务逻辑，仅提供调用入口、上下文与结果展示。
- 不取代核心平台 IAM/安全策略配置，但需消费相关能力进行鉴权与审计。
- 不覆盖纯语音坐席或外部客服系统，可通过集成方式嵌入。
- 不负责知识切分/训练算法细节，这部分由知识空间构建场景承担。
- 不提供离线客户端能力，本场景聚焦 Web 与 MiniApp 在线体验。

## 依赖与接口
- **IAM 与会话服务**：提供登录态、权限校验、审计 ID 关联。
- **智能体编排引擎**：暴露 Agent 调用、ReAct 工作流、节点状态查询与重试接口。
- **插件/工具目录服务**：查询插件元数据、输入输出结构、调用凭证。
- **知识空间与检索服务**：提供文档索引、知识片段 API、引用追踪能力。
- **提示模板与剧本服务**：管理常用 Prompt、对话片段、审批模板。
- **消息与通知服务**：发送进度提醒、人工接管通知、异常告警。
- **审计与合规服务**：存储对话日志、敏感字段脱敏、留存与检索接口。
- **文件与多模处理服务**：支持 OCR、语音转写、表格解析、矢量化等能力。

## 验收要点
1. 支持文本、语音、图片、文档等多模输入，并能在 2 秒内完成意图识别与 Agent 推荐。
2. 执行时间线需实时呈现 ReAct 步骤、调用插件、输入输出摘要，可回放/重试关键节点。
3. 知识引用需展示来源、版本与权限状态，引用错误时提供替代建议或审批流程。
4. 人工接管流程需与工单/审批系统打通，保障通知可靠、权限校验完备与审计可追溯。
5. 对话历史需支持检索、分享、导出，并在权限边界内隔离不同租户与用户。
6. 敏感操作需触发二次确认或 MFA，所有交互记录与上下文注入需写入审计日志。

## 场景级测试用例示例

> **测试准备**：搭建 Web `agent-ui-web-stg` 与 MiniApp `agent-ui-mini-stg` 沙箱，接入智能体编排引擎 `orchestrator-core`、知识空间服
务 `knowledge-hub`、提示模板服务 `prompt-kit`、插件目录 `addon-registry`、通知服务 `notify-hub`、审计服务 `audit-trail`、文件处理
服务 `file-vision`。创建租户 `tenant-b`，用户 `user-zoe`（业务人员）、`user-max`（智能体管理员）、`user-nina`（客服）、`user-ian`（合
规）。预置智能体 `agent-rag`, `agent-finance`, `agent-ops`, 插件 `contract-analyzer`, `report-bot`，知识空间 `knowledge-contract`, `know
ledge-finance`。

### 用例 A-1：多模输入意图识别成功（正向）
- **前置条件**：`user-zoe` 拥有 `agent-rag`、`agent-finance` 调用权限。
- **操作步骤**：
  1. 在 Web 端上传合同 PDF，输入“帮我生成执行摘要并计算付款节点”。
  2. 选择系统推荐的“合同分析智能体”意图卡片。
- **预期结果**：
  - 界面展示解析到的关键字段（金额、对方名称、日期）。
  - 推荐 `agent-rag` + `contract-analyzer` 工作流，提示预计耗时。
  - 推荐在 2 秒内出现，可编辑后发起执行。

### 用例 A-2：文件解析失败回退（逆向）
- **前置条件**：`file-vision` 服务故障。
- **操作步骤**：
  1. 在 MiniApp 上传 Excel 并发起意图识别。
- **预期结果**：
  - 系统提示“文件解析失败”，提供手动选择 Agent 的入口。
  - 记录错误日志并通知 `user-max`。
  - 对话继续保留文本输入区域供用户手动描述任务。

### 用例 B-1：知识引用与上下文裁剪（正向）
- **前置条件**：`knowledge-contract` 可用，`user-zoe` 有引用权限。
- **操作步骤**：
  1. 在对话侧栏搜索“付款条款”，拖拽知识片段到对话框。
  2. 启动任务并查看执行时间线。
- **预期结果**：
  - 知识片段显示来源文档、版本号、引用标识。
  - ReAct 时间线展示“思考 → 检索 → 分析”步骤及关联知识。
  - 上下文长度自动裁剪，保留关键信息。

### 用例 B-2：知识权限不足（逆向）
- **前置条件**：撤销 `user-zoe` 对 `knowledge-finance` 的引用权限。
- **操作步骤**：
  1. 试图插入 `knowledge-finance` 片段。
- **预期结果**：
  - 系统提示权限不足并提供申请入口。
  - 审计日志记录尝试引用行为。

### 用例 C-1：多 Agent 协同展示（正向）
- **前置条件**：`agent-rag` 与 `agent-finance` 均可调用。
- **操作步骤**：
  1. 发起“整理合同并生成付款提醒邮件”的复合任务。
  2. 查看执行时间线。
- **预期结果**：
  - 时间线展示 `agent-rag` 检索摘要、`agent-finance` 计算计划、`report-bot` 生成邮件草稿的连续步骤。
  - 每步可展开查看输入输出、耗时与调用插件。
  - 用户可对第二步追加备注并触发重新计算。

### 用例 C-2：执行失败回退（逆向）
- **前置条件**：模拟 `report-bot` 返回错误。
- **操作步骤**：
  1. 观察时间线提示。
  2. 点击“使用备用模板重试”。
- **预期结果**：
  - 时间线标记失败步骤并给出错误原因。
  - 触发预设回退策略，调用备用模板成功输出结果。
  - 告警推送至 `user-max` 并写入审计。

### 用例 D-1：人工接管并转工单（正向）
- **前置条件**：任务涉及高风险转账操作。
- **操作步骤**：
  1. 执行中达到风险阈值，界面弹出“需要人工审批”。
  2. 指派给客服 `user-nina`，并补充说明。
- **预期结果**：
  - `user-nina` 收到通知并在界面接管，查看上下文。
  - 人工审核通过后结果写回时间线，标记人工节点。
  - 系统自动生成工单并关联对话记录。

### 用例 D-2：人工接管超时升级（逆向）
- **前置条件**：`user-nina` 未在 SLA 内响应。
- **操作步骤**：
  1. 等待超时。
- **预期结果**：
  - 系统自动升级给 `user-ian` 并触发短信提醒。
  - 对话中显示升级记录，任务暂停等待处理。

### 用例 E-1：对话收藏与分享（正向）
- **前置条件**：完成一次成功对话。
- **操作步骤**：
  1. 点击“收藏并生成模板”。
  2. 设置分享范围为团队。
- **预期结果**：
  - 生成模板包含指令、上下文、执行步骤摘要。
  - 团队成员可在模板库中看到并复用。
  - 审计日志记录分享与访问行为。

### 用例 E-2：导出失败告警（逆向）
- **前置条件**：模拟审计导出服务故障。
- **操作步骤**：
  1. 在对话历史中尝试导出 PDF。
- **预期结果**：
  - 界面提示导出失败并提供重试与离线生成选项。
  - 记录告警并通知 `user-ian`。
  - 对话仍保留可访问状态。
