# 联系通道

PowerX 文档与插件生态团队使用个人微信作为统一入口，扫码后会拉你进入企业微信群进行实时沟通。无论是场景勘误、Usecase Seed 需求还是脚本使用问题，都可以通过该通道获得最快响应。

申请添加好友时，请备注产品名称，比如：“我关注PowerX”
<p align="center">
  <img src="/images/wx-qr-code.jpg" alt="PowerX 文档支持微信群二维码" width="220" />
</p>

> 温馨提示：这是个人微信号，请在备注中写明所属团队/公司与联系人姓名，方便管理员拉群。二维码若失效，可发送邮件至 `tech@artisan-cloud.com` 获取最新链接。

## 适用场景

- 文档、场景或 Usecase Seed 需要勘误与补充。
- 插件对接、Workflow 发布、PXIP 规范等遇到阻塞，需要官方指引。
- 想加入内测计划或同步最新发布节奏。

## 使用步骤

1. 打开微信/企业微信扫码添加管理员个人微信。
2. 备注公司、项目与目的（例如“XX 团队-插件联调问题”）。
3. 管理员会在 1 个工作日内拉你入群，群内可 @PowerX Docs Admin 获得支持。
4. 若需分享敏感数据，请先在群内描述问题，再单独私聊管理员处理。
