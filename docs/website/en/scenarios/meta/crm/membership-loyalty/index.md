# Membership & Loyalty

The Membership & Loyalty module manages tier entitlements, points/stored value, and member engagement activities, helping enterprises build long-term value and loyalty systems.

- **[Loyalty Points & Incentives](./loyalty-points-incentives/primary.md)** - Points accrual, redemption, expiration, and risk control
