# Contact Channel

We use a personal WeChat account as the entry point. After you add the contact, we will invite you into the official PowerX Docs group for faster collaboration.

<p align="center">
  <img src="/images/wx-qr-code.jpg" alt="PowerX Docs support QR code" width="220" />
</p>

> This QR code points to an individual WeChat ID. Please leave your team/company name and purpose in the note so we can add you to the right group. If the code expires, email `tech@artisan-cloud.com` for the latest contact.

## When to reach out

- Documentation gaps, scenario/usecase seed requests, localization updates.
- Troubleshooting publish scripts, workflow specs, PXIP changes.
- Emergency comms for release blockers or to join early-access programs.

## Steps

1. Scan the QR code with WeChat/WeCom.
2. Send a note (e.g., “ACME – Plugin rollout questions”).
3. We will add you to the group within one business day. Mention **@PowerX Docs Admin** for priority help.
4. Share sensitive data only via direct message with an admin after describing the issue.
