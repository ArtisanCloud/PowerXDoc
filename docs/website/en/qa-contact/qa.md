# Support FAQ

## Missing or outdated scenarios/usecases
- Check `docs/_data/docmap.yaml` and `docs/scenarios/**` first.
- Share the `SCN_ID` or business context in the group; we can help prioritize updates.

## Publish script errors
- Provide the exact command plus the corresponding `reports/*.json` file.
- If the resume token is invalid, run a fresh `--dry-run` to generate a new one and retry.

## QR code/contact expired
- Email `tech@artisan-cloud.com` and we will send the latest entry point.

## Large documentation requests
- Prepare background, target audience, and desired artifacts (scenario/usecase/guide/etc.).
- We will confirm details in the group and schedule it in the PowerXDocs backlog; complex topics may require a sync call.

## Security & confidentiality
- Describe the issue first, then share sensitive logs privately with an admin via encrypted channel.
- All support requests follow internal confidentiality policies.

> Still stuck? Contact us via the [Contact Channel](/en/qa-contact/contact) and ping **@PowerX Docs Admin** for real-time assistance.
