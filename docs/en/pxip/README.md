# PowerX Integration Proposals (PXIP)

PXIPs document major architectural changes, standards, and governance decisions for the PowerX platform. Each proposal captures motivation, high-level design, backwards compatibility, and rollout considerations.

- Browse individual proposals in this directory to understand the rationale behind core platform capabilities.
- Follow the PXIP template when authoring new proposals to maintain a consistent review process.
