### **特性一｜多智能体协作与灵活工作流**

**标题：**

> 多智能体协作商业场景，灵活配置工作流，快速落地企业自动化。

**说明文案：**
PowerX 内置智能体与工作流引擎，可让企业在同一平台上 orchestrate（编排）多智能体协同工作。
从审批流、客服自动化，到 AI 文档分析、销售自动触达，均可通过可视化 Flow 快速实现业务落地。

**关键词：**

> Multi-Agent · Flow Engine · 企业自动化

---

### **特性二｜插件化应用开发与能力互通**

**标题：**

> 一切功能皆为插件，数据与能力在底座中自然互通。

**说明文案：**
PowerX 提供统一的插件运行时与契约层，所有业务模块都以插件形式存在。
插件之间通过底座的 IAM、RBAC、EventBus、Flow 等机制共享身份与事件，实现跨插件能力复用。
开发者可基于 PowerXPlugin 脚手架快速开发、调试、注册插件。

**关键词：**

> Plugin Architecture · Contract Bridge · Shared CoreX Runtime

---

## 🧩 PowerX 产品矩阵（Product Matrix）

> 一套统一的企业数字化基座 + 插件生态 + 市场体系。

---

### **1. PowerX Core Base（企业级底座）**

**定位：**
企业内核与运行时引擎。提供统一的多租户、身份、权限、事件、审计、工作流能力。

**核心模块：**

* IAM（身份与组织管理）
* RBAC（权限控制）
* EventBus（事件总线）
* Flow Engine（可编排执行流）
* Audit（全局审计与合规）

**一句话总结：**

> PowerX 内核 = 企业系统的操作系统层。

---

### **2. PowerX Plugin Scaffold（插件脚手架）**

**定位：**
插件开发框架与项目模板，帮助开发者快速创建、构建和调试插件。

**说明文案：**
提供前后端一体化脚手架（Go + Nuxt），内置 CLI 工具与 SDK。
开发者可通过 `powerx-cli init` 一键生成插件项目，快速集成宿主内核。

**关键特性：**

* 标准化目录结构
* 自动注册 manifest（plugin.yaml）
* 支持 HTTP / gRPC / MCP 三种通讯协议
* 一键打包发布（.pxp 格式）

**一句话总结：**

> 用脚手架 30 分钟生成一个可运行的企业插件。

---

### **3. PowerX Plugin Market（插件市场）**

**定位：**
官方 + 第三方插件生态中心，统一管理插件安装、升级与授权。

**说明文案：**
提供插件发现、下载、购买与授权管理能力。
支持企业私有市场与公有市场模式，具备版本控制与安全签名机制。

**关键特性：**

* 插件上架与审核
* 版本发布与回滚
* License 授权与计费
* 安装依赖自动管理

**一句话总结：**

> 像 App Store 一样，管理你的企业插件生态。

---

### **4. 官方插件应用层（Built-in Applications）**

**定位：**
开箱即用的通用业务模块，满足主流企业应用场景。

**内置示例插件：**

| 插件名称                | 功能说明            |
| ------------------- | --------------- |
| **PowerX CRM**      | 客户、销售线索、机会与合同管理 |
| **PowerX Commerce** | 多店铺商品、库存、订单、结算  |
| **PowerX SCRM**     | 社交营销、粉丝运营与私域触达  |
| **PowerX SCRUM**    | 敏捷协作与项目任务管理     |
| **PowerX Wallet**   | 企业钱包与交易结算组件     |

**一句话总结：**

> 5 个即插即用的官方插件，快速构建你的企业系统雏形。
