# 主用例说明：库存与推荐联动（Inventory & Recommendation Orchestration）

## 背景概述

在社交运营中，商品推荐、促销活动、群推消息需要结合实时库存与供应链能力。若库存不足仍大量推广，容易造成客户体验下降；反之库存积压又难以及时曝光。本主用例覆盖 ERP 库存预警、上新同步、区域差异策略与智能推荐联动，让社交侧运营精准匹配库存情况。

## 目标与价值
- **实时预警**：库存紧张时及时调整推荐策略，避免超卖。
- **高效消化库存**：库存充足或积压时加大曝光与优惠力度。
- **区域差异化**：根据仓储和物流能力制定不同地区的社交策略。
- **数据闭环**：库存变化与社交转化关联，优化供应链决策。

## 参与角色
- **供应链/仓储团队**：提供库存、到货、调拨信息。
- **社交运营**：调整内容、活动、推荐策略。
- **销售团队**：基于库存情况制定客户沟通计划。
- **数据科学团队**：构建推荐与预警模型。
- **IT/中台团队**：维护与 ERP、推荐引擎的接口。

## 主场景 User Story
> **作为** 社交运营负责人，**我希望** 库存变化能实时驱动推荐策略与活动计划，**从而** 提升转化并降低缺货投诉。

## 子场景详解

### 子场景 A：库存预警驱动社交提醒
- **角色与触发**：某热门商品库存低于安全线。
- **主要流程**：
  1. ERP 触发库存预警事件，推送到 SCRM 中台。
  2. SCRM 根据策略暂停对应商品的群发或广告推广。
  3. 通知销售与客服调整话术，改为推荐替代品。
  4. 预警解除后自动恢复推广，并记录影响范围。
- **成功标准**：库存预警及时；社交侧不再推广缺货商品；替代品推荐有效。
- **异常与风控**：预警消息未达时自动重试；替换活动失败需人工确认；保留预警闭环日志。
- **指标建议**：预警响应时间、缺货投诉率、替代品转化率。

### 子场景 B：新品上新与曝光加速
- **角色与触发**：新品到货需要快速在社交侧曝光。
- **主要流程**：
  1. ERP 记录新品入库并通知 SCRM。
  2. SCRM 自动生成上新素材、直播提醒与群公告草稿。
  3. 推荐引擎优先推送给潜在用户，结合预售或试用计划。
  4. 运营监控曝光与转化，对营销动作做实时调整。
- **成功标准**：新品上线信息 10 分钟内触达目标客户；素材自动生成；曝光与转化可监控。
- **异常与风控**：素材生成失败回退至人工模式；曝光过度可设置上限；库存不足时动态调节推送频次。
- **指标建议**：上新触达率、转化率、库存周转天数。

### 子场景 C：区域库存与推荐策略
- **角色与触发**：不同仓库库存差异明显，需要区域化运营。
- **主要流程**：
  1. ERP 提供区域库存报表；SCRM 计算各区域库存健康度。
  2. 系统根据客户所在城市自动匹配推荐商品、物流承诺。
  3. 当某区域库存积压时，群活动与优惠重点投放该区域客户。
  4. 效果回传供应链，辅助调拨或补货决策。
- **成功标准**：推荐与库存匹配；区域活动效果明显；供应链获得决策依据。
- **异常与风控**：定位失败时使用默认策略；区域库存数据延迟后自动降级；优惠策略设定上限防止亏损。
- **指标建议**：区域库存周转、推荐点击率、区域活动 GMV。

### 子场景 D：推荐模型与库存联动优化
- **角色与触发**：运营希望通过算法将库存与客户意向结合。
- **主要流程**：
  1. 推荐模型接入实时库存、价格、客户偏好数据。
  2. 输出基于库存权重的推荐列表，避免推荐下架商品。
  3. A/B 测试不同权重配置，寻找转化与库存消化平衡点。
  4. 模型效果反馈到数据团队，持续迭代。
- **成功标准**：模型推荐准确；库存消化效率提升；A/B 测试数据可靠。
- **异常与风控**：模型权重异常时可回滚；过度推荐导致库存被抢空时触发限流；保留模型版本。
- **指标建议**：推荐触达转化率、库存周转改善幅度、模型命中率。

## 场景级测试用例示例

> 测试准备：搭建 ERP 与 SCRM 联调环境、库存事件模拟器、推荐引擎、运营控制台与 A/B 实验平台。

### 用例 A-1：库存预警停止推广（正向）
- **前置条件**：商品 A 安全库存 100，实际库存 80。
- **操作步骤**：
  1. ERP 发送库存低于阈值事件。
  2. 查看 SCRM 活动、推荐状态。
- **预期结果**：
  - SCRM 暂停商品 A 的群发与广告计划，提示运营替换内容。
  - 销售看板显示替代商品建议。
  - 日志记录预警时间、受影响活动、恢复条件。

### 用例 B-1：区域库存积压推荐策略（逆向）
- **前置条件**：东部仓库存积压，西部仓紧张。
- **操作步骤**：
  1. 同步区域库存差异数据。
  2. 查看不同城市客户收到的推荐。
- **预期结果**：
  - 东部客户优先收到促销信息和优惠券；西部客户看到替换商品或延迟配送提示。
  - 推荐报表呈现区域维度数据；供应链收到调拨建议。
  - 若同步失败，系统退回默认策略并告警。
