# 主用例说明：统一身份与私有化部署（Unified SSO & Private Deployment）

## 背景概述

大型企业通常拥有多套系统（SCRM、CRM、ERP、OA），要求统一身份认证（SSO）与私有化部署，以满足安全与合规。本主用例描述如何实现统一登录、权限同步、多因子认证以及私有化部署方案，确保数据安全与用户体验。

## 目标与价值
- **统一登录体验**：一次登录访问多系统，减少账号管理负担。
- **安全增强**：多因子认证、设备管理、IP 白名单。
- **私有化控制**：支持内网部署、混合云、数据主权。
- **权限同步**：与组织架构联动，自动分发权限。

## 参与角色
- **IT/基础架构团队**：搭建 SSO、部署环境。
- **安全与合规团队**：制定安全策略、审计。
- **业务系统管理员**：配置权限、同步组织架构。
- **运维团队**：监控系统健康、处理故障。
- **审计人员**：定期检查访问与权限记录。

## 主场景 User Story
> **作为** IT 管理员，**我希望** 实现统一身份认证和私有化部署，**从而** 保证安全合规并提供一致体验。

## 子场景详解

### 子场景 A：统一身份集成
- **角色与触发**：企业已有 SSO（AD/LDAP/IDaaS）。
- **主要流程**：
  1. 将 SCRM 注册为 SSO 应用，配置 SAML/OIDC。
  2. 同步组织架构、角色、用户信息。
  3. 支持单点登录、单点登出、密码策略。
  4. 提供统一成员审计与生命周期管理。
- **成功标准**：登录成功率高；用户体验顺畅；数据同步稳定。
- **异常与风控**：认证失败回退本地账号；同步冲突记录；敏感角色需审批。
- **指标建议**：SSO 登录成功率、同步延迟、异常次数。

### 子场景 B：安全策略与多因子认证
- **角色与触发**：加强访问安全。
- **主要流程**：
  1. 配置 MFA（短信、OTP、企业微信确认、硬件令牌）。
  2. 设置访问策略：IP 白名单、设备指纹、风险评分。
  3. 异常登录自动锁定并通知安全团队。
  4. 提供自助解锁、密码重置流程。
- **成功标准**：安全策略有效；用户可快速验证；日志完整。
- **异常与风控**：MFA 失败允许备用方式；风险登录需审批；敏感操作二次验证。
- **指标建议**：MFA 成功率、风险登录拦截率、误报率。

### 子场景 C：私有化部署与混合云
- **角色与触发**：企业需保证数据不出境或独立部署。
- **主要流程**：
  1. 提供容器化部署包、安装指南、依赖清单。
  2. 配置高可用、备份、灾备策略。
  3. 支持本地存储、日志与监控系统对接。
  4. 定期发布补丁与升级包，提供灰度策略。
- **成功标准**：部署顺利；性能达标；升级可控。
- **异常与风控**：安装失败提供回滚；补丁包含校验；数据加密。
- **指标建议**：部署时长、可用率、升级成功率。

### 子场景 D：审计与合规报告
- **角色与触发**：满足监管与内部审计。
- **主要流程**：
  1. 收集登录、权限变更、数据访问日志。
  2. 生成审计报告，可按时间、用户、操作筛选。
  3. 支持导出供外部审计或合规审查。
  4. 提供异常行为分析与整改追踪。
- **成功标准**：日志完整；报告符合要求；整改可闭环。
- **异常与风控**：日志写入失败告警；访问日志加密；遵守法规保留期。
- **指标建议**：日志完整率、审计通过率、异常整改率。

## 场景级测试用例示例

> 测试准备：配置 SSO 沙箱、MFA、私有化部署环境、日志系统、审计模板。

### 用例 A-1：SSO 登录与同步（正向）
- **前置条件**：AD 已配置，用户存在。
- **操作步骤**：
  1. 使用 SSO 登录 SCRM。
  2. 检查组织架构与权限同步。
- **预期结果**：
  - 登录成功，用户信息来自 AD。
  - 权限自动分配，组织结构保持一致。
  - 日志记录登录成功与同步详情。

### 用例 B-1：异常登录拦截（逆向）
- **前置条件**：配置 IP 白名单，模拟外部异常访问。
- **操作步骤**：
  1. 在非白名单 IP 尝试登录。
  2. 观察系统行为。
- **预期结果**：
  - 登录被拒绝，并提示异常。
  - 安全团队收到告警。
  - 审计日志记录此次尝试。
