# 页面 08｜B1 智能体是什么（认知校准页）

## 页面目标
统一“定义边界”：回答智能体“是什么/不是什么/怎么判断”，不展开运行机制细节。

## 页面展示（PPT 怎么做）

### 版式
- 顶部 20%：标题区
  - 主标题：`B1 智能体是什么`
  - 副标题：`一句话讲清：它不是聊天工具，而是结果导向的数字岗位`
- 中部 55%：三栏认知框架（定义 / 常见误解 / 判定标准）
  - 左栏（33%）：`定义：它到底是什么`
  - 中栏（33%）：`常见误解：它不是什么`
  - 右栏（34%）：`判定标准：什么才算智能体`
- 底部 25%：一句定义 + 边界条
  - 定义文案：`智能体 = 在授权边界内，为业务目标持续做决策并推动执行的数字岗位。`
  - 边界文案：`人定目标与红线，智能体负责高频决策与执行编排。`

### 图上文案（可直接粘贴）
- 定义：它到底是什么（左栏）
  - `有明确经营目标：如线索成本下降、转化率提升`
  - `能自主编排多步动作：分析 -> 选择策略 -> 推送执行`
  - `会基于结果持续优化：不是一次跑完就结束`
- 误解：它不是什么（中栏）
  - `不是“会聊天”的机器人`
  - `不是只会写文案/出图的内容工具`
  - `不是固定规则的自动化脚本（IFTTT/RPA）`
- 判定标准：什么才算智能体（右栏）
  - `是否对“业务结果”负责，而不只是对“任务完成”负责`
  - `是否能跨渠道协同执行，而不只做单点动作`
  - `是否能根据反馈自动调整策略，而不靠人工重配`
- 结论条（放中下）
  - `能完成经营目标闭环，才叫智能体。`

### 动效顺序（建议）
1. 先出三栏标题（定义 / 常见误解 / 判定标准）。
2. 再依次出现三栏要点：定义 -> 常见误解 -> 判定标准。
3. 最后出现底部定义与边界条，收口“人机分工”。

## 讲述脚本（怎么讲）

### 时间分配（本页 3 分钟）
- 第 1 分钟：先给定义
  - 重点句：先定义对象，后讨论能力，否则会把工具当智能体。
- 第 2 分钟：拆三类误解
  - 重点句：智能体不是聊天、不是生成、不是脚本自动化。
- 第 3 分钟：给判断标准与边界
  - 重点句：不是 AI 替代岗位，而是给岗位一个可闭环的数字分身。

### 讲师话术（可直接用）
- 开场：`这一页只做一件事：统一“智能体”的定义边界。`
- 过渡：`先回答“是什么/不是什么”，团队才能避免在选型和建设上跑偏。`
- 收口：`下一页 B2 再讲机制：智能体具体如何形成闭环并持续学习。`

## 为什么这样设计

- 用“三栏校准”替代“机制展开”
  - 原因：B1 的任务是统一概念，不是讲技术流程。
- 单列“如何判断”
  - 原因：让听众带着判断尺子进入后续页面。
- 底部保留“边界条”
  - 原因：定义阶段就明确治理责任，减少后续争议。
