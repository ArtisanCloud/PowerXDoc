# 页面 06｜营销智能化阶段（轻量版）

## 页面目标
承接上一页趋势结论，明确第四阶段的定义：营销从“数据驱动人”进入“目标驱动系统”。

## 页面展示

### 页面结构
- 顶部 20%：标题区
  - 主标题：`第四阶段：营销智能化`
  - 副标题：`从看见问题，到系统持续做决策并闭环优化`
- 中部 60%：一个闭环图 + 三个价值标签
  - 闭环主链路：`目标 -> 策略 -> 执行 -> 反馈 -> 学习`
  - 价值标签：`更快响应`、`更稳转化`、`更低试错成本`
- 底部 20%：人机分工条
  - 文案：`AI 负责建议与编排，人负责目标、授权与边界。`

### 图上文案
- 目标：明确增长目标与约束条件
- 策略：自动生成渠道/内容/预算建议
- 执行：跨渠道自动编排与任务下发
- 反馈：实时回收线索、转化、成本数据
- 学习：基于结果自动调参并迭代策略

### 演示节奏（建议）
1. 先出现标题与一句定义（目标驱动系统）。
2. 再按顺时针出现闭环 5 个节点。
3. 最后出现底部“人机分工条”，避免误解成“AI 替代人”。

## 讲解提示

### 时间分配（本页 3 分钟）
- 第 1 分钟：先定义变化
  - 重点句：数字化让我们看清问题，智能化让系统持续处理问题。
- 第 2 分钟：讲闭环价值
  - 重点句：关键不是一次建议，而是“持续决策 + 持续优化”的循环。
- 第 3 分钟：讲治理边界
  - 重点句：智能体做执行编排，人保留目标与边界控制权。

### 讲师话术
- 开场：`本页定义第四阶段的核心能力：目标驱动的持续决策系统。`
- 过渡：`当市场变化速度超过人工协同速度，决策机制需要系统化升级。`
- 收口：`营销智能化的价值在于提升组织确定性，并释放团队高价值决策能力。`

## 为什么这样设计

- 用“闭环图”替代长段说明
  - 原因：更直观看到智能化是持续过程，不是单点工具。
- 价值标签只保留三项
  - 原因：便于高层快速记忆和复述。
- 单独放“人机分工条”
  - 原因：提前化解“AI 替代人”的常见疑虑。
