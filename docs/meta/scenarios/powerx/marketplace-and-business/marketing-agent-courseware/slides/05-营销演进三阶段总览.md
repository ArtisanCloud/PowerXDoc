# 页面 05｜营销演进三阶段总览（轻量版）

## 页面目标
用更轻的表达说明一件事：营销市场一直在跟着技术变，今天正在从“数据驱动”走向“智能驱动”。

## 页面展示

### 页面结构
- 顶部 20%：标题区
  - 主标题：`营销演进：技术在重写增长方式`
  - 副标题：`从经验到系统到数据，正在迈向智能协同`
- 中部 60%：三张卡片 + 一条趋势箭头（左到右）
  - 卡 1：传统营销（靠人）
  - 卡 2：信息化营销（靠系统）
  - 卡 3：数字化营销（靠数据）
  - 箭头尾注：`下一步：营销智能化（靠智能体持续决策）`
- 底部 20%：一句结论
  - 文案：`技术每升级一次，营销都更快、更准、更可复制。`

### 卡片文案
- 传统营销（靠人）
  - 关键词：经验、人脉、个人能力
  - 典型结果：起量快，但复制难
- 信息化营销（靠系统）
  - 关键词：CRM、流程化、线上协同
  - 典型结果：效率提升，但系统常割裂
- 数字化营销（靠数据）
  - 关键词：追踪、看板、A/B 测试
  - 典型结果：看得更清楚，但响应仍偏慢

### 演示节奏（建议）
1. 标题和趋势箭头先出现。
2. 三张卡片依次出现（靠人 -> 靠系统 -> 靠数据）。
3. 最后出现“下一步：营销智能化（靠智能体持续决策）”。

## 讲解提示

### 时间分配（本页 3 分钟）
- 第 1 分钟：传统到信息化
  - 重点句：先把经验沉淀成流程，营销开始可管理。
- 第 2 分钟：信息化到数字化
  - 重点句：再把流程沉淀成数据，营销开始可度量。
- 第 3 分钟：收口到下一页
  - 重点句：当变化速度继续上升，下一步就是把数据能力升级为持续决策能力。

### 讲师话术
- 开场：`本页聚焦一个主线：技术升级持续推动营销方式演进。`
- 过渡：`各阶段均提升了可控性，同时对响应速度提出更高要求。`
- 收口：`下一页进入“营销智能化阶段”，重点说明能力升级路径。`

## 为什么这样设计

- 从“多维对比”改为“趋势叙事”
  - 原因：降低信息密度，让听众先抓住主线。
- 每张卡片只保留“关键词 + 结果”
  - 原因：避免过载，适合口头展开。
- 保留“下一步”箭头
  - 原因：让第 06 页衔接自然，不突兀。
