# 课程母稿：PowerX 营销智能体（1-2 小时）

## 页级文档（PPT 制作入口）

- 目录文件：`slides/00-目录.md`
- 页级文档路径：`docs/meta/scenarios/powerx/marketplace-and-business/marketing-agent-courseware/slides/`

## 课程定位

- 受众：甲方业务负责人、增长负责人、市场负责人、数字化负责人
- 目标：建立“营销智能化”统一认知，并形成 90 天可落地试点方案
- 课程时长：90-120 分钟（推荐 110 分钟）

## 一、课程总目标（3 分钟）

1. 讲清营销从传统到智能化的演进规律。
2. 讲清“智能体”是什么、原理是什么、在营销中的现实作用是什么。
3. 让学员带走一套可执行的试点路径（30/60/90 天）。

---

## 二、课程议程（110 分钟建议版）

1. 模块 A：营销演进四阶段（20 分钟）
2. 模块 B：营销智能体基础（25 分钟）
3. 模块 C：营销智能体三大场景（35 分钟）
4. 模块 D：增长飞轮与经营指标（15 分钟）
5. 模块 E：落地方法与试点路径（15 分钟）

> 压缩到 90 分钟：每个模块减少 3-5 分钟，保留案例。
> 扩展到 120 分钟：增加行业分组讨论与答疑。

## 三、模块 A：营销演进四阶段（20 分钟）

### A1-A3 一页总览：传统 -> 信息化 -> 数字化（15 分钟）

- 传统营销（经验驱动）
  - 核心特征：渠道与人脉主导，强个人能力，弱流程沉淀。
  - 主要问题：复制难、规模化成本高、组织依赖“关键人”。
- 营销信息化（系统支撑）
  - 核心特征：CRM/OA/呼叫中心等上线，流程电子化、可留痕。
  - 主要问题：系统烟囱明显，数据有记录但难协同、难决策。
- 营销数字化（数据驱动）
  - 核心特征：投放-线索-成交链路可追踪，A/B 测试常态化。
  - 主要问题：仍是“人找数据做判断”，响应速度受人力上限制约。
- 讲解建议：A1-A3 作为一张对比页展示（阶段特征、组织形态、决策方式、主要瓶颈四列）。

### A4. 营销智能化：智能体增强（5 分钟）

- 特征：从“数据驱动人”升级到“目标驱动系统”。
- 决策方式：系统持续给出策略建议并推动执行，结果自动反馈再学习。
- 组织形态：人机共治，AI 负责建议与编排，人负责授权与边界。
- 核心价值：从“流程提效”走向“经营增益”。

## 四、模块 B：营销智能体基础（25 分钟）

### B1. 智能体是什么（6 分钟）

- 定义：智能体不是聊天机器人，而是围绕经营目标持续决策并推动执行的业务单元。
- 营销语境下：它是“增长岗位的数字分身”，能感知、判断、行动、复盘、优化。
- 关键区别：
  - 自动化工具：按固定规则执行任务。
  - 营销智能体：在业务目标和治理边界内动态选策略。

### B2. 智能体原理（非技术版，8 分钟）

营销智能体最核心闭环：

1. 感知：读取用户行为、线索状态、活动结果、交易反馈。
2. 判断：结合目标（如转化率/复购率）评估“当前最优动作”。
3. 行动：触发内容、触达、分配、优惠、节奏调整等动作。
4. 反馈：监测打开率、回复率、下单率、复购率等结果。
5. 迭代：更新策略优先级，让下一轮更准确。

> 一句话：营销智能体 = 会学习的经营闭环，而非一次性流程编排。

### B3. 营销智能体在现阶段的现实作用（7 分钟）

1. 策略助理：辅助人做更快、更稳的策略判断。
2. 执行编排器：将跨部门、跨渠道动作串联成统一节奏。
3. 预测预警器：提前识别下滑风险并给出干预建议。
4. 复盘优化器：自动归因并产出下一轮优化计划。

### B4. 现阶段边界（4 分钟）

- 不是“全自动替人”，而是“人机协同增强”。
- 人必须保留三类权力：预算授权、品牌边界、合规审查。
- 智能体必须满足三项治理：可解释、可审计、可干预。

### B5. 智能体工程化底座：Skill / MCP / Tool Call（补充 4 分钟）

- Skill（按 Claude Code 最新规范）
  - 载体：每个技能是一个目录，入口文件为 `SKILL.md`。
  - 规范：遵循 Agent Skills 开放标准，Claude Code 在标准上扩展了调用控制、子代理执行、动态上下文注入等能力。
  - 核心 frontmatter：`name`、`description`、`disable-model-invocation`、`allowed-tools`、`context`、`agent`。
  - 实战含义：把营销方法论（如“活动复盘”“渠道诊断”“增长实验设计”）沉淀成可复用技能资产。
- MCP（Model Context Protocol）
  - 作用：把 CRM、广告平台、BI、内容库等外部系统以标准协议接入智能体。
  - 价值：统一工具接入层，避免“每个智能体重复造接口”。
  - 实战含义：策略、内容、业务三个智能体可共享同一批企业工具与数据源。
- Tool Call（工具调用）
  - 定义：模型在推理中发起结构化工具请求，系统执行后回填 `tool_result`，再由模型继续决策。
  - 价值：把“会说”升级为“会做”，形成可执行、可审计的行动闭环。
  - 实战含义：营销智能体不仅给建议，还能真实触发查询、生成、投放、同步等动作。

## 五、模块 C：营销智能体三大场景（35 分钟）

> 结构：每个场景由 1 个主智能体 + 3 个子智能体协同完成。

### C1. 场景 1：策略智能体（12 分钟）

- 子智能体 1：市场调研
  - 输入：行业趋势、竞品动态、渠道变化、政策信号。
  - 输出：机会地图、风险清单、优先赛道建议。
- 子智能体 2：用户洞察
  - 输入：行为数据、交易数据、客服语料、社媒反馈。
  - 输出：人群分层、需求画像、流失/转化关键因子。
- 子智能体 3：方案策划
  - 输入：经营目标与预算边界。
  - 输出：季度/活动策略包（目标、路径、节奏、指标、资源分配）。
- 业务价值：从“拍脑袋策略”升级为“证据驱动策略”。
- 关键指标：策略命中率、实验成功率、策略迭代周期。

### C2. 场景 2：内容智能体（12 分钟）

- 子智能体 1：文案撰写
  - 输入：人群画像、渠道规范、品牌语调、活动目标。
  - 输出：多版本文案（广告文案、私域触达、落地页话术等）。
- 子智能体 2：视觉设计
  - 输入：品牌规范、素材库、活动主题。
  - 输出：海报/主图/信息流素材建议与设计稿。
- 子智能体 3：视频制作
  - 输入：脚本、镜头模板、商品卖点、平台规范。
  - 输出：短视频脚本、分镜、可发布的视频素材版本。
- 业务价值：内容产能与一致性同步提升，缩短上线周期。
- 关键指标：内容生产周期、素材复用率、点击率/完播率。

### C3. 场景 3：业务智能体（11 分钟）

- 子智能体 1：流量运营
  - 输入：流量结构、投放表现、站内外行为数据。
  - 输出：预算分配建议、节奏调整策略、流量预警。
- 子智能体 2：渠道管理
  - 输入：多渠道数据（公域/私域/电商/线下）。
  - 输出：渠道优先级、协同动作编排、渠道冲突治理建议。
- 子智能体 3：产品定价
  - 输入：成本、库存、需求弹性、竞品价格、活动策略。
  - 输出：价格带建议、促销策略、毛利与销量平衡方案。
- 业务价值：把策略与内容转成经营动作，提升收入与效率。
- 关键指标：ROI、渠道贡献度、毛利率、支付转化率。

## 六、模块 D：增长飞轮与经营指标（15 分钟）

### D1. 营销智能体增长飞轮（7 分钟）

- 路径：获客 -> 培育 -> 转化 -> 复购 -> 策略再学习。
- 与传统闭环差异：
  - 传统：链路通了，但每轮重来。
  - 智能：每轮都沉淀策略资产，下一轮更优。

### D2. 指标体系（8 分钟）

- 效率指标：响应时长、自动化覆盖率、人均线索承载量。
- 转化指标：线索转商机率、商机胜率、支付转化率。
- 价值指标：复购率、留存率、LTV、营销 ROI。
- 治理指标：策略可解释率、人工干预率、风险事件闭环率。

---

## 七、模块 E：落地方法与试点路径（15 分钟）

### E1. 三阶段落地（10 分钟）

1. 0-30 天：单点试点
   - 只选一个高价值场景（建议先“线索培育”或“成交转化”）。
   - 明确对照组和目标指标。
2. 31-60 天：双场景联动
   - 打通“获客->培育”或“培育->转化”。
   - 建立策略回放和复盘机制。
3. 61-90 天：闭环运营
   - 接入复购策略，形成完整增长飞轮。
   - 建立季度优化节奏与治理机制。

### E2. 试点成功标准（5 分钟）

- 业务层：核心转化指标显著改善。
- 组织层：跨部门协作效率提升。
- 治理层：关键策略可审计、可回放、可兜底。

## 八、讲师使用说明（授课建议）

- 开场 10 分钟先统一认知，不急着讲产品功能。
- 每个场景都用“痛点 -> 智能决策点 -> 业务指标”结构讲解。
- 避免陷入技术细节，聚焦经营价值与组织可执行性。
- 课程最后必须落到试点方案，否则难形成行动。

---

## 九、课堂互动题（可选）

1. 你所在团队目前处于四阶段中的哪一阶段？判断依据是什么？
2. 你最优先解决的是获客、培育、转化、复购中的哪一环？为什么？
3. 你们组织里哪些决策可先交给智能体建议，哪些必须人工最终拍板？

---

## 十、课后作业模板（可直接布置）

1. 定义一个 90 天营销智能体试点目标（不超过 2 个指标）。
2. 选择一个场景，写出当前人工流程与智能体流程对比。
3. 明确人机分工边界（授权、合规、品牌）。
4. 输出每两周一次复盘机制与决策迭代机制。

---

## 十一、对外主张（可用于结语）
>
> 营销智能化不是把营销流程“再系统化一次”，而是把企业的经营决策能力产品化、持续化、可复用化。  
> 真正的价值不只是节省人力，而是提高增长确定性。
