采用三层结构：

> **类别（Category） → 主用例（Primary Use Case） → 子用例（Scenario Use Case）**
> 每个子用例都遵循「角色 + 触发 + 行为 + 目标」叙事风格，确保具备真实业务场景感。

# 🧩 PowerX 场景化用例总清单

---

## Ⅰ. 核心平台层（Core Platform）

### 🗂️ 身份与访问控制（IAM / RBAC）

**主用例：多租户与组织管理**

* 企业管理员创建新租户以隔离不同业务部门的数据环境
* 运营人员在同一租户下添加多个业务子部门并配置结构层级
* 集团管理员将两个租户间的客户数据共享给特定用户进行协作
* 系统在租户到期后自动冻结其访问权限并提示续约

**主用例：用户与角色管理**

* 管理员导入员工信息并自动生成默认用户账号
* 企业采用 OIDC 登录，系统自动同步组织架构与用户角色
* 管理员为项目组成员批量分配角色与权限策略
* 员工离职后系统自动撤销其关联权限

**主用例：登录与认证**

* 用户通过公司 SSO 登录并进入统一管理门户
* 第三方服务调用 PowerX API 通过 Token 认证接入
* 管理员启用 MFA 双重验证确保敏感插件安全
* 安全系统检测异常登录并强制登出会话

---

### ⚙️ 系统运行与配置（Runtime & Ops）

**主用例：插件安装与启停**

* 开发者在测试租户中手动安装本地插件进行调试
* 企业管理员从 Marketplace 一键安装官方插件
* 系统检测新版本插件并自动触发升级任务
* 运维人员手动停用存在风险的插件

**主用例：系统监控与告警**

* 监控服务检测到插件异常 CPU 占用并自动限流
* 运维通过控制台查看插件健康状况与性能曲线
* 系统发现异常日志触发 Webhook 告警
* 管理员收到告警后远程重启插件

**主用例：事件与任务流管理**

* 插件发布事件后系统自动通知订阅方
* 任务调度器根据时间规则定期触发插件任务
* Agent 监听事件流并生成自动任务节点
* 延迟队列重新执行失败任务

---

### 🤖 流程自动化执行（PowerX RPA）

**主用例：RPA 执行引擎深度集成 CoreX**

* 企业智能体在 Workflow 中插入 “RPA Step”，通过 CoreX 调度 Browser/ Desktop/API Runner 执行跨系统指令
* 运营人员使用可视化构建器录制网页/桌面操作并生成标准 RPA Flow JSON，通过触发器定时或手动运行
* RPA 插件托管账号凭据、会话 Cookie 与文件处理任务，执行日志回传统一可观测性与 ACL 审计
* 典型流程包括政府投标信息抓取、CRM↔ERP 对账同步、OA 待办收集与日报生成，支持按执行次数或行业套餐计费

---

## Ⅱ. 插件生态层（Plugin Ecosystem）

### 🧱 插件生命周期（Plugin Lifecycle）

**主用例：插件创建与初始化**

* 开发者使用 CLI 初始化新插件工程并自动生成模板文件
* 团队成员从 Git 仓库克隆现有插件项目进行二次开发
* 企业技术组导入第三方提供的插件源码包进行适配

**主用例：插件开发与调试**

* 开发者在本地宿主模拟环境中运行插件进行热更新调试
* 插件在沙箱模式中自动加载测试数据集进行功能验证
* 调试工具捕获插件错误并输出日志报告

**主用例：插件发布与上架**

* 开发者完成测试后直接将插件推送到测试租户验证
* 管理员在无网络环境中通过离线包导入插件
* CI/CD 流程自动构建并发布插件至生产租户
* 系统在夜间执行灰度发布并收集运行指标
* Vendor 提交插件到 Marketplace 审核与上架

**主用例：插件版本与兼容性管理**

* 系统自动检测插件版本并提示可升级版本
* 管理员手动回滚至上一版本以应对异常
* 插件声明与宿主版本不兼容时阻止安装

**主用例：WebAdmin 插件运行监控**

* 运维在 WebAdmin → Plugin Manager 中按租户/节点总览所有插件状态、版本与实例数量
* 页面实时展示 CPU、内存、网络吞吐、队列积压、任务成功率并可导出指标
* 支持一键重启/停用/限流/滚动升级，操作受 ACL 控制且写入审计日志
* 详情页提供日志检索、任务执行记录、告警阈值配置与通知订阅，帮助定位异常

---

### 🔗 插件通信与集成（Integration & Connectivity）

**主用例：插件能力注册与暴露**

* 插件启动时注册 HTTP 和 gRPC 接口供宿主调用
* 插件通过 MCP 注册智能工具以供 Agent 使用
* 插件在事件总线上声明可订阅的主题

**主用例：宿主调用插件**

* PowerX 核心服务通过 gRPC 请求插件计算结果
* 系统根据租户策略转发 HTTP 请求至对应插件实例
* 调用失败后宿主自动触发重试机制

**主用例：插件调用宿主**

* 插件使用 PowerX SDK 查询租户信息与用户权限
* 插件在执行任务后回传结果事件到宿主 EventBus
* 插件调用宿主 API 更新全局配置

**主用例：插件间通信**

* 插件 A 发布事件，插件 B 监听并执行联动逻辑
* 不同业务插件通过共享 Topic 实现跨模块同步
* 数据流插件将清洗结果推送至报表插件进行分析

---

### 🔒 插件安全与合规（Security & Compliance）

**主用例：插件签名与验证**

* 开发者在发布前对插件包进行本地签名
* 系统在安装时校验插件签名与完整性
* Marketplace 验证插件来源与证书合法性

**主用例：权限与访问控制**

* 插件声明所需权限范围由宿主审核授权
* 管理员动态调整插件访问资源范围
* 用户尝试越权访问插件时被系统拦截

**主用例：License 管理**

* 用户购买插件后生成 License Key 并绑定租户
* License 到期后系统自动禁用插件能力
* Vendor 发布新版本后更新 License 校验规则

---

## Ⅲ. 智能体与自动化层（Agent & Automation）

### 🧠 智能体编排（Agent Orchestration）

**主用例：智能体任务执行**

* 主 Agent 接收自然语言任务并自动识别目标插件
* 多个 Agent 并行执行不同子任务并汇总结果
* Agent 在任务失败后自动重试或请求人工干预
* Agent 触发插件工作流完成业务自动化

**主用例：智能体注册与管理**

* 插件在启动时注册自带 Agent 工具集
* 用户创建自定义 Agent 用于内部知识问答
* 系统监控 Agent 状态并统计任务执行效率

**主用例：ReAct 智能体编排**

* 主 Agent 依据知识空间检索结果生成推理—行动计划
* Agent 在对话中交替执行思考、调用插件与观察反馈
* 风险控制策略确保 ReAct 链路超时或失败时可快速回滚
* 审计面板记录每步 ReAct 思考链与工具调用上下文

**主用例：智能体工作流编排**

* 运营人员在可视化画布上编排内核节点与插件节点组成业务流程
* 场景团队为特定租户复制并调整现有工作流模板
* 智能体根据运行时上下文动态选择分支与循环策略
* 系统对关键节点配置人工审核与异常回滚策略

**主用例：智能体模型与平台接入**

* 运维在 `backend/config/agents` 中登记新的 LLM/VLM/TTS/Embeddings Provider 并完成密钥托管
* 多模型路由根据成本、延迟、合规级别自动选择最优模型或 fallback 策略
* Coze、n8n 等外部智能体平台通过连接器纳入统一编排与审计
* 成本、配额与健康信号实时可视化，异常调用自动限流或告警

---

### 📚 知识与推理（Knowledge & Reasoning）

**主用例：知识空间构建**

* 用户上传企业文档创建专属知识空间
* 系统自动解析文档结构并生成向量索引
* 管理员定义不同部门的知识访问权限

**主用例：智能问答与推理**

* 员工在聊天界面提问，Agent 从知识库中召回答案
* Agent 结合上下文自动引用多篇文档生成回复
* 用户反馈错误答案后 Agent 自动修正检索策略

**主用例：知识更新与反馈**

* 定期同步外部知识源并重新训练嵌入
* 系统识别知识空白并提示上传新文档
* Agent 根据用户互动自动优化知识优先级

## Ⅳ. 市场与商业层（Marketplace & Business）

### 🏪 插件市场运营（Marketplace Operations）

**主用例：Vendor 入驻与审核**

* 第三方开发者注册 Vendor 账号并提交资质材料
* Marketplace 管理员审核通过后开通开发者空间
* Vendor 管理团队成员与插件资产权限
* 审核不通过时提供整改指引并沉淀合规记录

**主用例：插件上架与销售**

* Vendor 提交插件包并填写定价与说明
* Marketplace 审核通过后将插件上架公有市场
* 用户浏览 Marketplace 并购买订阅插件
* Vendor 配置权益包、试用与促销策略以适配多类租户
* Marketplace 运营跟踪销售表现并触发下架或降权决策

**主用例：计费与结算**

* Marketplace 配置订阅、按量与混合计费模型，并定义阶梯、溢价等策略
* 系统实时采集插件调用、资源消耗与增值服务指标生成周期账单
* 企业用户核验账单后通过在线支付、合同付款或余额抵扣完成续订
* Marketplace 与 Vendor 按分润规则出具结算单并对接财税开票
* 风控系统监测异常用量与欠费风险，触发限流、催缴与争议处理流程

## Ⅵ. 用户与前端体验层（Admin / Web / MiniApp）

### 🖥️ 管理后台（Web Admin ）

**主用例：后台导航与权限控制**

* 平台产品规划后台导航信息架构，维护多租户可复用的菜单模板
* 系统根据用户角色与权限策略动态渲染导航入口与操作按钮
* 租户管理员按需启用/隐藏插件菜单并进行灰度发布与快速回滚
* 敏感操作触发二次确认、MFA 或审批流程，防止越权风险
* 审计人员追踪导航与权限变更记录，导出差异报告与整改工单

**主用例：开发者调试与工具**

* 开发者在 Web Admin 调试工作台中实时查看插件/Agent 日志并关联 Trace
* 使用内置 Schema/配置校验工具识别缺失字段、兼容性问题并快速回滚
* 对 Agent 或插件执行轨迹进行断点重放，重现问题并导出调试报告
* 在同一界面监控性能指标，触发临时扩容、限流或降级策略并追踪效果
* 自动生成诊断建议并同步至工单、知识空间，形成跨团队协同闭环

---

### 📱 用户端体验（Web / MiniApp）

**主用例：用户与会话中心**

* 用户在统一入口查看已安装插件、授权范围、计费状态与最近活动
* 系统将插件更新、智能体任务通知与安全提醒集中投递到消息中心
* 用户可自助管理第三方账号绑定、会话设备、登录历史与异常提醒
* 租户管理员为特定用户或群组定制首页模块、快捷操作与推荐插件
* 安全团队配置敏感操作的二次验证、会话失效与数据导出留痕策略

**主用例：智能体交互界面**

* 用户在 Web/MiniApp 聊天界面输入自然语言或上传文件，由系统自动识别意图并调度合适 Agent
* 多 Agent 协作执行任务，界面实时展示工具调用、插件执行与上下文摘要的状态流
* 用户通过提示模板、上下文片段与知识空间引用快速构建复杂指令，并支持插入结构化表单
* 对话历史、执行记录与回溯步骤可收藏共享，便于跨团队复用与合规审计
* 当智能体无法完成任务时，界面支持人工接管、发起工单或切换到备用策略，保障业务连续性

**主用例：业务插件前端交互**

* 插件以 iframe / Web Component 形式嵌入 Web Admin、MiniApp 业务页面，并继承宿主的导航与布局容器
* 宿主向插件注入统一的主题、国际化、权限与租户上下文，确保视觉一致性与安全边界
* 插件通过前端 SDK 与宿主事件总线交换状态，实现会话信息、选中对象、消息通知等跨页面同步
* 租户管理员可配置插件入口、默认参数与灰度策略，按业务角色定制不同页面体验
* 系统持续监控插件前端性能与可用性，异常时支持降级为宿主兜底页面或暂时关闭入口
