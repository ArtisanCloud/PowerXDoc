# 主用例说明：用户与商品分析

## 背景概述
PowerX 电商平台需要为运营团队提供精准的用户与商品分析能力，支撑热销排行、RFM 分群、A/B 测试。随着精细化运营重要提升，数据分析成为决策依据。本主用例聚焦"用户与商品分析"全流程，覆盖热销商品排行、高价值客户分群、A/B 测试评估三大核心场景，确保分析精准、优化有效、转化提升。

## 核心子场景

### 子场景 A：热销商品排行
- **主要流程**：根据浏览与下单数据生成热销排行榜，指导运营重点推广。

### 子场景 B：RFM 客户分群
- **主要流程**：基于 RFM 模型分群，识别高价值客户，制定针对性营销策略。

### 子场景 C：A/B 测试评估
- **主要流程**：测试不同页面布局转化率差异，数据支持页面优化决策。

## 验收要点
1. 热销排行准确，指导意义明确。
2. RFM 分群有效，客户洞察深入。
3. A/B 测试结果可靠，优化方向清晰。
