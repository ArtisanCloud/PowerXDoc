# 主用例说明：积分与储值

## 背景概述

PowerX 电商平台需要为用户提供积分与储值管理能力，支撑积分获取、使用抵扣、储值通用、异常监控。随着积分经济普及，积分成为提升用户活跃度的重要工具。本主用例聚焦"积分与储值"全流程，覆盖下单积分奖励、积分抵扣消费、储值多店通用、积分异常监控四大核心场景，确保积分透明、使用便捷、监控有效。

## 核心子场景

### 子场景 A：下单获得积分
- **主要流程**：用户购买￥1000 商品，系统自动奖励 1000 积分（1:1 比例），VIP 会员享受 2 倍积分。

### 子场景 B：积分抵扣消费
- **主要流程**：用户结算时使用 500 积分抵扣￥5，积分不足时提示补充或使用其他优惠。

### 子场景 C：储值余额通用
- **主要流程**：用户在 A 店充值￥1000，在 B 店消费￥300，储值余额自动更新为￥700，多店通用无障碍。

## 验收要点
1. 积分获取自动准确，抵扣计算正确。
2. 储值多店通用，余额同步及时。
3. 积分异常及时监控，异常率<0.1%。
