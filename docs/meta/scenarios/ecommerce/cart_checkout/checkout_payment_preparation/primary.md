# 主用例说明：结算与支付准备

## 背景概述

PowerX 电商平台需要为用户提供完整且安全的结算与支付准备能力，支撑地址选择、运费计算、发票开具、风控审核等关键环节。结算页是转化漏斗的最后一环，任何细节疏漏都可能导致用户流失。本主用例聚焦"结算与支付准备"全流程，覆盖地址与配送校验、费用透明展示、风控审核触发三大核心场景，确保支付流程顺畅、费用透明、风控有效。

## 目标与价值
- **地址智能管理**：支持多地址管理、配送范围校验、运费实时计算。
- **费用透明展示**：清晰展示商品价、运费、税费、优惠后总额，避免纠纷。
- **配送可达性校验**：实时验证配送地址可达性，承诺准确配送时效。
- **风控审核机制**：检测异常订单，触发人工审核，保障交易安全。
- **发票灵活开具**：支持多种发票类型，满足企业/个人不同需求。

## 参与角色
- **企业终端用户**：在结算页选择地址、发票、配送方式，确认订单信息。
- **财务与发票专员**：审核企业发票申请、处理开票申请、管理发票库存。
- **风控审核团队**：审核异常订单、评估风险等级、处理风险事件。
- **物流配送团队**：计算运费、承诺配送时效、处理特殊地区配送。
- **系统自动化任务**：校验配送范围、计算费用明细、触发风控审核。

## 主场景 User Story
> **作为** 企业终端用户，**我希望** 在结算页清晰查看所有费用明细并完成支付准备，**从而** 确认订单信息无误并顺利完成支付。

## 子场景详解

### 子场景 A：用户选择配送地址并校验可达性
- **角色与触发**：用户在结算页选择收货地址，系统需要校验配送范围并计算运费。
- **主要流程**：
  1. 用户在结算页点击"选择收货地址"。
  2. 展示历史地址列表：
     - 北京朝阳区家（默认）
     - 上海浦东公司
     - 广州天河父母家
  3. 用户选择"北京朝阳区家"，地址详情：详细地址、收货人、电话。
  4. 系统调用物流 API 校验配送范围：
     - 配送区域：北京全市可配送
     - 配送时效：次日达
     - 运费：满￥99 免运费，不满￥99 收取￥10 运费
  5. 当前订单商品总价￥299，不满免运费标准。
  6. 系统计算运费￥10，总金额￥309。
  7. 用户确认地址与配送信息，订单进入下一步。
- **成功标准**：地址选择便捷；配送校验准确；运费计算正确；时效承诺清晰。
- **异常与风控**：地址不详细无法配送；特殊地区（新疆、西藏）运费单独计算；地址冲突处理。
- **指标建议**：地址选择转化率、配送校验成功率、运费计算准确率、配送时效达成率。

### 子场景 B：选择发票类型并展示费用明细
- **角色与触发**：用户需要开具发票，在结算页选择发票类型与开票信息。
- **主要流程**：
  1. 用户在结算页选择发票类型：
     - 不开发票
     - 个人普通发票
     - 企业增值税专用发票
  2. 用户选择"企业增值税专用发票"。
  3. 填写开票信息：
     - 公司名称：北京 ABC 科技有限公司
     - 税号：91110000123456789X
     - 注册地址：北京市朝阳区 XX 路 XX 号
     - 开户行：中国银行北京分行
     - 账号：1234567890123456789
     - 电话：010-12345678
  4. 系统验证发票信息完整性与准确性。
  5. 展示费用明细：
     - 商品总额：￥299
     - 运费：￥10
     - 税费：税率 13%，￥40.17
     - 优惠：满减￥20
     - 应付总额：￥329.17
  6. 用户确认发票信息与费用明细，完成结算准备。
- **成功标准**：发票选择灵活；信息填写便捷；费用明细清晰；税费计算准确。
- **异常与风控**：税号格式错误；企业信息不完整；发票库存不足；税号重复检测。
- **指标建议**：发票开具率、信息填写完整率、费用明细查看率、结算完成率。

### 子场景 C：系统检测订单异常触发风控审核
- **角色与触发**：用户提交订单后，系统检测到订单金额异常高。
- **主要流程**：
  1. 用户提交订单：购买 10 台 iPhone 15 Pro，总价￥79990。
  2. 系统实时风控引擎检测：
     - 异常金额：单笔订单超过￥50000
     - 风险评分：80 分（高风险）
     - 风险特征：新注册账号、首次大额购买、收货地址与支付地址不一致
  3. 系统触发风控审核流程：
     - 订单状态变为"待审核"
     - 自动发送审核工单至风控团队
     - 订单暂不发货，等待审核结果
  4. 风控审核员查询订单详情：
     - 用户信息：新注册 3 天，历史订单 0 笔
     - 收货地址：北京某小区
     - 支付方式：信用卡，信用卡办理时间 1 个月
  5. 审核员致电用户核实购买意图。
  6. 用户确认是企业批量采购，审核通过。
  7. 订单状态更新为"已审核"，正常进入发货流程。
  8. 用户收到订单审核通过通知。
- **成功标准**：异常检测及时；审核流程顺畅；误判率低；用户感知好。
- **异常与风控**：误判影响用户体验；审核超时延迟发货；黑名单用户拦截；恶意攻击应对。
- **指标建议**：风控拦截准确率、审核通过率、审核平均耗时、用户投诉率。

### 子场景 D：配送时效计算与承诺
- **角色与触发**：用户选择地址后，系统需要计算准确配送时效。
- **主要流程**：
  1. 用户选择收货地址：上海浦东新区。
  2. 系统查询物流时效：
     - 仓库位置：上海仓（有库存）
     - 配送距离：20km
     - 配送时效：当日达（11:00 前下单）或次日达
     - 当前时间：10:00
  3. 系统承诺配送时效：
     - 预计送达：今日 18:00 前
     - 配送费用：￥0（满￥99 免运费）
  4. 用户选择配送时间：
     - 工作日配送（周一至周五 9:00-18:00）
     - 周末配送（周六 9:00-12:00）
  5. 特殊区域时效计算：
     - 北京五环内：次日达
     - 北京六环外：2-3 日达
     - 偏远地区：3-5 日达
  6. 配送时效承诺写入订单，作为服务标准。
- **成功标准**：时效计算准确；承诺时间合理；特殊区域识别；用户可选择时间。
- **异常与风控**：时效承诺无法达成；天气影响配送；节假日时效调整；配送超时赔付。
- **指标建议**：时效计算准确率、配送按时率、用户满意度、配送超时率。

### 子场景 E：优惠与积分使用抵扣
- **角色与触发**：用户在结算页使用优惠券与积分抵扣现金。
- **主要流程**：
  1. 用户购物车商品总价￥350。
  2. 用户选择可用优惠：
     - 新用户券：满￥300 减￥50
     - 会员积分：500 积分抵扣￥5
  3. 系统应用优惠：
     - 商品原价：￥350
     - 新用户券：-￥50
     - 积分抵扣：-￥5
     - 小计：￥295
  4. 用户选择支付方式：微信支付。
  5. 最终支付金额：￥295。
  6. 优惠使用记录：
     - 新用户券：已使用，不可重复使用
     - 积分：500 积分已扣减
  7. 用户收到订单确认信息。
- **成功标准**：优惠计算准确；积分抵扣正确；支付金额无误；优惠记录清晰。
- **异常与风控**：优惠过期处理；积分不足抵扣；优惠叠加冲突；重复使用拦截。
- **指标建议**：优惠使用成功率、积分抵扣准确率、订单支付成功率、优惠后转化率。

### 子场景 F：特殊商品配送限制
- **角色与触发**：用户购买特殊商品（电池、液体），需要特殊配送处理。
- **主要流程**：
  1. 用户购买商品清单：
     - iPhone 15 Pro（正常商品）
     - 锂电池充电宝（危险品）
     - 香水（液体限制）
  2. 系统检测商品属性：
     - 锂电池：航空禁运品，陆运限制数量
     - 香水：液体，单瓶≤100ml 可空运，超限需陆运
  3. 计算配送时效与费用：
     - 锂电池：陆运，3-5 日达，运费￥20
     - 香水：空运（100ml），2-3 日达，运费￥15
     - iPhone 15 Pro：空运，1-2 日达，运费￥0
  4. 整体订单时效：3-5 日达（取最长）。
  5. 总运费：￥20+￥15=￥35。
  6. 用户确认配送信息，订单进入待发货状态。
- **成功标准**：特殊商品识别准确；配送方案合理；时效计算正确；用户知情。
- **异常与风控**：禁运品识别；配送限制地区；包装要求；法律风险防控。
- **指标建议**：特殊商品识别率、配送方案合理性、用户满意度、违规配送零发生。

## 功能边界 & 不目标场景
- 不涉及具体支付网关接入与支付流程（支付与账单域处理）。
- 不处理退款退货费用计算。
- 不覆盖跨境配送的清关与税务问题。
- 不涉及复杂的企业采购审批流程。

## 依赖与接口
- **地址管理系统**：管理用户地址、验证地址格式、查询配送范围。
- **物流配送 API**：计算运费、查询时效、提供配送承诺。
- **费用计算引擎**：计算商品总价、运费、税费、优惠后金额。
- **发票管理系统**：管理发票类型、填写开票信息、验证税号。
- **风控审核引擎**：检测异常订单、评估风险等级、触发审核流程。
- **优惠积分系统**：管理优惠券、积分规则、计算抵扣金额。

## 验收要点
1. 支持地址选择与配送校验，配送范围判断准确率≥99%，运费计算误差率≤1%。
2. 费用明细清晰展示（商品价、运费、税费、优惠后总额），用户可快速理解。
3. 风控审核触发及时，高风险订单拦截准确率≥95%，审核耗时≤10 分钟。
4. 配送时效承诺准确，时效达成率≥95%，配送超时有补偿机制。
5. 发票信息填写便捷，发票开具准确率≥99%，企业税号验证实时有效。
